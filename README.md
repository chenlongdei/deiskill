# deiskill

**一句话说出你想要的结果，剩下的步骤让 AI 去跑。** 找资料、扒字幕、建知识库、写学习计划、出日报，这些平时要切好几个工具、花一下午的事，现在在对话里说一句就能开始。

一套中文 AI Skills，能装在 Claude Code、Codex、WorkBuddy 等支持 Skills 的 Agent 上。**AI 只负责听懂你要什么、第一次帮你配好；固定的动作都写成了脚本**，所以换 Agent、换电脑结果都一样，定时任务跑起来也不花 AI 额度。采用 [MIT 许可](LICENSE)，少数目录例外，见[依赖、成本与许可](#依赖成本与许可)。

> **招牌功能：抖音关键词巡检。** 告诉它几个关键词，它会定期在抖音指数里搜近几天的热门视频，像真人一样一条条点开看，把数据和逐字稿整理成表，还会跨期累计哪些视频反复上榜。登记好之后由电脑自己按时跑，**不用开 Agent，不花 AI 额度**，一轮 5 个词约 1 元转写费。→ [看看它怎么用](#每-3-天帮我扒一次抖音上这几个关键词的热门视频)

## 你可以这样用

### 「每 3 天帮我扒一次抖音上这几个关键词的热门视频」

比如「商业思维、女性成长、女性情感、豆包工作、WorkBuddy」五个词。它会：

1. 在抖音创作者中心的**抖音指数**里搜视频，按你定的条件筛选：近 3 天、时长、垂类（比如女性类的词只看「情感」）；
2. 每个词看前两页，**一条条点开**，按真人的节奏停留、翻页，关键词之间休息几分钟，降低被风控的可能；
3. 每看完一条就把音频交给阿里云转写，看完最后一条，逐字稿也差不多齐了；
4. 交给你一张汇总表：视频指数、点赞、评论、收藏、分享、推荐量、视频标签、「大家都在搜」、逐字稿和链接；
5. 另有一张**跨期总表**，记录每条视频第一次和最近一次上榜、一共上榜几轮，哪些是持续爆的内容一眼就能看出来。

**为什么说它省心**

- **只设置一次**：第一次它带你走四步：自检、用抖音 App 扫码登录、试跑两条、登记定时。之后由电脑系统按时自动跑，Agent 关着也照跑。
- **不花 AI 额度**：所有固定动作都写进了脚本，跑的时候不调用任何大模型。换成 Codex、WorkBuddy，或者换一台电脑，结果都一样。
- **不用买插件**：只需要 Chrome 和一个抖音账号，不需要社媒助手等付费插件。
- **不怕改版**：页面上的筛选点不动时，会自动改用页面背后的同一个搜索接口，结果一致。
- **结果干净**：没有人说话的视频（字幕加配乐）标成「无口播」；音频拿不到时自动换视频文件，再不行走去水印接口，并把原因写在表里；常错的词（比如把 WorkBuddy 听成「沃克巴迪」）自动改正；以前采过的视频不会重复转写。

一次实测：5 个词、98 条视频，84 分钟跑完，转写费约 1 元，AI 消耗为 0。→ 表格长什么样见[成品展示](#成品展示)。

### 「我想学会 Claude Code，给我一份从入门到精通的学习计划」

1. 用中英文关键词搜 YouTube，按播放量和频道去重，筛出 15—30 个精选教程，**先给你确认**；
2. 把这些视频导入 NotebookLM，建成一个知识库；
3. 用 7 个问题把它们整理成知识地图，按「道、法、术、器、用」分层；
4. 交给你一份分单元的学习计划（观看顺序、练习、验收标准），外加一本**不懂技术也能照着做**的实操手册。某一层资料不够时，它会自己回去补搜。

全程你只需要确认 3 次：精选清单、单元划分、手册任务。想在通勤路上听，还可以给每个单元生成一期中文音频。
→ 实际产出见[成品展示](#成品展示)。

### 「拿这几本书和这些视频，帮我把『私域运营』这个主题挖深」

先问清你的研究目的，列出问题树给你确认，再用 7 个问题交叉追问所有资料。最后交出一份研究综述：哪些是共识，哪里有分歧，各自的依据是什么，你可以怎么做。遇到说不清的概念，可以接着把它拆开讲清楚；研究的是你自己的生意，可以接着做商业诊断。

### 「给我今天的日报」

一份报告看完四个渠道：前一天新闻联播里的政策和商机、AI 圈的新动向、知乎热榜上值得写的选题、你关注的抖音博主发了什么。每个渠道都会回看近 7 天，告诉你**哪些变化单看一天是看不出来的**。还能做成可以直接发出去的图卡和长图。

### 「把这几条视频转成文字」「导出这个博主的全部文案和点赞数据」

抖音、快手、小红书、B 站的短视频链接，YouTube 视频，本地录音，都能转成逐字稿。也可以盯住几个博主的更新，或者把一个抖音博主的全部历史作品导成一张表，文案和点赞、评论数据一一对齐。要花钱的操作，批量超过 20 条时会先报条数和大概费用。

## 5 分钟尝鲜

只装依赖最少的 `dei-capture`。需要 Python 3.9+ 和 [yt-dlp](https://github.com/yt-dlp/yt-dlp)（`pip install yt-dlp`），不用注册任何账号：

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash -s -- dei-capture
```

重启 Agent，然后对它说：

> 搜一下 YouTube 上关于 Claude Code 的入门教程

第一次它会问你 [dei 工作区](#结果存在哪里) 放在哪里，之后在工作区的 `02_采集/` 里交给你一份 `清单.md`：

```text
## 推荐（66）

### 1. CLAUDE CODE FULL COURSE 4 HOURS: Build & Sell (2026)
- 频道：Nick Saraev
- 播放：2.9M · 时长：4:10:43
- 链接：https://www.youtube.com/watch?v=…
- 命中关键词：Claude Code build real project
```

接下来可以说「把第 3 个视频的字幕扒下来」。第一次扒字幕时，它可能会请你允许读取一个已登录 YouTube 的浏览器的 cookies。想把这些视频变成学习计划，再装上 `dei-notebook` 和 `dei`。

## 安装

**macOS / Linux** 一键安装（仓库会放在 `~/.deiskill/repo`）：

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash
```

**Windows**：在 PowerShell 里运行（需要先装好 git 和 Python 3.9+，缺哪个脚本会告诉你用 winget 怎么装）：

```powershell
irm https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.ps1 | iex
```

不想敲命令：把这个仓库的网址发给你的 Agent，说「帮我安装 deiskill，按 README 操作」。

也可以手动安装：

```bash
git clone https://github.com/chenlongdei/deiskill.git
cd deiskill
bash scripts/install.sh                 # 检测本机已有的 Agent；有多个时会问你装到哪些
bash scripts/install.sh dei-capture     # 只装指定的 Skill
bash scripts/install.sh --target ~/.claude/skills --target ~/.workbuddy/skills   # 指定目录
bash scripts/install.sh --list          # 查看全部 Skill
```

Windows 上把 `bash scripts/install.sh` 换成 `python scripts\install.py`，参数相同。

- **支持哪些 Agent**：安装器会自动识别 Claude Code（`~/.claude/skills`）、Codex（`~/.codex/skills`）、WorkBuddy（`~/.workbuddy/skills`）和 `~/.agents/skills`。其他支持 Skills 的 Agent，用 `--target <它的 skills 目录>` 指定；实在不行，把 `skills/` 下对应的文件夹整个复制进去也能用。
- **定时任务**：用系统自带的定时工具（macOS launchd、Windows 任务计划程序、Linux cron）直接运行脚本，和用哪个 Agent 无关，Agent 关着也照跑。macOS 上保存位置在外接盘、桌面或文稿时，第一次会提示你给 Python 开「完全磁盘访问权限」，并给出要添加的路径。
- **缺依赖怎么办**：不用提前装全。第一次用到某个功能时，Skill 会先自检，告诉你缺什么，并按你的系统（macOS / Windows / Linux）给出一条安装命令，你同意后再装。
- **第一次用任何一个 Skill 时**，它会问你 dei 工作区放在哪里，见[结果存在哪里](#结果存在哪里)。
- **重装或升级时**，旧版本会备份到 `~/.deiskill/backups/<时间>/`，你的配置和运行数据会自动保留。
- 凭证只写进本机的 `config.json`，不进 Git。各 Skill 的 `config.example.json` 列出了全部配置项。

## 结果存在哪里

所有 Skill 共用一个「dei 工作区」。第一次用任何一个 Skill 时，它会给出 2—3 个建议位置，你确认后才创建，以后不再问。报告和数据都放在这里，不放进 Agent 的安装目录：

```text
dei工作区/
├── 使用说明.md
├── 01_我的清单/   你自己维护的表：抖音监控工作簿、选题表
├── 02_采集/       YouTube、抖音博主和关键词巡检、音视频转写
├── 03_日报/       综合日报（按年）、政策与商机、AI 情报、知乎热榜
├── 04_知识库/     一个主题一个文件夹：问答、学习路线
├── 05_成品/       准备发布的内容
└── 99_系统/       运行总账、日志、备份、试跑结果（平时不用看）
```

- **怎么命名**：一次性的结果按「日期_时间_主题」命名（北京时间），比如 `2026-11-13_1600_Claude-Code入门`；长期跟踪的博主、频道、知识库按名字命名。
- **找最近的产出**：每次运行都会在 `99_系统/运行总账.jsonl` 记一行，直接问 Agent「最近一次日报在哪」「上次关键词巡检的结果呢」就行。
- **试跑和正式分开**：试跑和测试的结果一律放进 `99_系统/测试/`；临时缓存 30 天后自动清理。
- **外接盘没插**：会直接报错，不会悄悄写到别处。
- **从旧版升级**：`python3 scripts/migrate_workspace.py --skills-dir <skills 目录> --to <新工作区>` 先预览要搬哪些文件，加 `--apply` 才真正搬，搬完可以撤回。

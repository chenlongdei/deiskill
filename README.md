# deiskill

**一个人做知识 IP 的 AI 工作系统：找到机会、学透、做成课、在朋友圈卖出去，再把结果沉淀成下一轮的素材。每一步都装着实战里用过的方法。**

一套中文 AI Skills，装在 Claude Code、Codex、WorkBuddy 等支持 Skills 的 Agent 上。你只需要说出想要的结果，总入口 `dei` 会把事情交给对的 Skill，在该停的地方停下来请你确认。采用 [MIT 许可](LICENSE)，少数目录例外，见[依赖、成本与许可](#依赖成本与许可)。

```text
        ┌──────────────────────────────────────────────────────────────┐
        ↓                                                              │
   ① 找机会  ──────→  ② 学透  ──────→  ③ 做成产品  ──────→  ④ 卖出去 ─┘
   日报 · 抖音巡检      知识库 · 学习计划    课程手册 · 物料包     朋友圈 · 发售 · 复盘
   盯对标博主           主题研究            讲师卡              素材库

   所有结果都存进同一个「dei 工作区」，下一步直接接着用；越用，素材和判断越多。
```

## 为什么不直接问 AI

**1. 装进去的是方法，不只是提示词。** 每个 Skill 背后都有一套实战里磨出来的做法，写成了 AI 能照着执行的步骤：

| 环节 | 方法 | 来自 |
| --- | --- | --- |
| 政策和 AI 日报 | 政策分 S / A / B / C 级；商机分「观察 → 验证 → 可进入 → 兑现」；从政策一路推到谁拍板、谁付钱、哪个环节赚钱 | 一门资本思维课程，用真实日报校准 |
| 学一个新软件 | 7 个问题封顶，按「道、法、术、器、用」分层，资料不够时自己回头补搜 | 一次 29 个教程的真实学习路线 |
| 做课 | 13 章手册结构、物料数据前后对得上、跨课埋伏笔、23 条踩坑清单 | 四节真实上过的 AI 办公课，六轮迭代 |
| 朋友圈 | 私域标签与可见范围、带原话证据的风格提示词、开头两行定生死、浪潮式发售 | 一次真实的课程发售 |

**2. 不编。** 这是所有 Skill 共同的铁律：数字、客户原话、截图不编，缺的地方留空让你补；拿不到字幕就写明失败原因，不拿标题拼一段「逐字稿」；结论标明证据强弱，资料里没有的写「资料未涉及」。你拿结果去发布、去卖东西，不会被 AI 坑。

**3. 越用越懂你的生意。** 日报每个渠道都回看近 7 天，写出单看一天看不出来的变化；抖音巡检有跨期总表，哪些内容一直在火一目了然；朋友圈的风格提示词和素材库每期都在长，这一期发售的结果就是下一期的案例。所有产出按「采集 → 日报 → 知识库 → 成品」放进同一个工作区，每次运行都记进总账，问一句「上次的结果在哪」就能接着做。

**4. 说结果就行，跑起来不费额度。** 你说「找一批教程，帮我做学习计划」，`dei` 会从最终交付倒推：先搜、再请你确认清单、再建知识库、再出计划。固定的动作都写成了脚本，所以换 Agent、换电脑结果都一样，定时任务不用开 Agent，也不花 AI 额度。

## 一条完整的链：从「学会一个软件」到「卖出一门课」

下面每一环都有真实产出，可以在[成品展示](#成品展示)里看到。

1. **学透**：「我想学会 Claude Code，给我一份从入门到精通的学习计划」
   搜出 29 个 YouTube 教程请你确认 → 导入 NotebookLM → 7 个问题拿到知识地图、5 单元学习计划、一本给非程序员的实操手册。
2. **做成产品**：「按这份学习计划，做一节教大家用 AI 写周报的课」
   先给你看场景人物、物料清单、手册目录 → 13 章学员手册、Win / Mac 物料包、讲师卡 → 推到你常用的飞书、Notion 或钉钉。
3. **卖出去**：「帮我把这门课在朋友圈卖出去」
   先用你的 3 条朋友圈做风格提示词 → 按浪潮式发售排好整个发售期，你认可节奏后再写前几天的文案和私聊开场。
4. **复盘、再来一轮**：「发售结束了，帮我复盘」
   真实的学员原话和数据写进素材库；下一次找选题、做课、发售时，它会先看这些。

你不用记住上面用了哪几个 Skill，从头到尾都只跟 `dei` 说话。

## 每一环能做什么

### ① 找机会

**「给我今天的日报」**：一份报告看完四个渠道：前一天新闻联播里的政策和商机、AI 圈的新动向、知乎热榜上值得写的选题、你关注的抖音博主发了什么。每个渠道都会回看近 7 天，没有强机会就写没有，不为每天都有商机而凑数。还能做成可以直接发出去的图卡和长图。

**「每 3 天帮我扒一次抖音上这几个关键词的热门视频」**：它在抖音指数里按你定的条件搜近几天的视频，像真人一样一条条点开，边看边转写，交给你一张汇总表（视频指数、点赞、收藏、分享、推荐量、标签、「大家都在搜」、逐字稿），外加一张跨期总表，记录哪些视频反复上榜。

第一次花几分钟做完自检、扫码、试跑、登记定时，之后电脑按时自己跑，**不用开 Agent，不花 AI 额度**。一次实测：5 个词、98 条视频，84 分钟跑完，转写费约 1 元。

**「盯住这几个对标博主」「导出这个博主的全部文案和点赞数据」**：一张监控工作簿，每个博主一页，左边是对方近 7 天的视频数据和逐字稿，右边留给你写自己的创作和复盘；也可以把一个博主的全部历史作品导成一张表。

### ② 学透

**「我想学会 X，给我一份从入门到精通的学习计划」**：搜 YouTube、请你确认精选清单、建知识库，用 7 个问题拿到知识地图、学习计划和实操手册。全程你只需要确认 3 次。想在通勤路上听，可以给每个单元生成一期中文音频。

**「拿这几本书和这些视频，帮我把『私域运营』这个主题挖深」**：先问清你的研究目的，列出问题树请你确认，再交叉追问所有资料，交出研究综述：哪些是共识、哪里有分歧、证据有多强、你可以怎么做、哪些还没被资料覆盖。说不清的概念可以接着拆开讲清楚；研究的是你自己的生意，可以接着做商业诊断。

### ③ 做成产品

**「按这份方案写第 1 节课手册，做物料包和讲师卡」**：13 章学员手册，Windows 和 Mac 都能直接解压的物料包，讲师练习卡和课后练习。物料里的数字互相对得上，手册里的成绩和耗时留空等你填真实记录。校对通过后，推到你常用的文档平台，下次改完直接更新同一个页面。

### ④ 卖出去

**「我的朋友圈发出去没人理，帮我把这次发售排好」**：

1. 先收你说过的话、写过的字：按住说话讲讲你的一天、你自己的几条朋友圈、几段聊天记录（先遮掉客户名字）。它反推出一段**带原话证据的风格提示词**，以后写什么都先用它；
2. 逐条告诉你那条朋友圈为什么没人停下来，也告诉你原文里哪些好东西要留下；
3. 按**浪潮式发售**排好整个发售期：哪几天只讲故事不卖、哪天是截止的浪头、每天发几条，再写好前几天的文案和私聊开场；
4. 发售期间你每晚花两分钟记数据，结束后帮你复盘，把真实的反馈收进素材库。

**「明天见一个做餐饮的老板，我怎么介绍自己」「按这份课程手册给我配几个案例」**：先把你的经历和案例建成一案一卡的案例库，分清哪些是你亲手做的、哪些是学员做的，数字能算成一年省多少时间、多少钱。之后每次讲课、见人、发资料，它都从库里挑出最对路的 1—3 个案例，写好 1 / 3 / 10 分钟的自我介绍、PPT 人物页和案例页；给老板、给个人、给政企社区各出一版介绍 PDF，内部附录不会被发出去。

### 随时可用：转文字

抖音、快手、小红书、B 站的短视频链接，YouTube 视频，本地录音，都能转成逐字稿。要花钱的操作，批量超过 20 条时会先报条数和大概费用。

## 两种装法：全套，或只装一个

**装全套**（推荐）：以后只跟 `dei` 说话，它会按你的需求调用对应的 Skill。

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash
```

Windows PowerShell：`irm https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.ps1 | iex`

**只装一个**：只想用其中一项，或者课上只讲一个 Skill 时，只装它就能独立用，不用准备全套的浏览器、账号和密钥。以后再装全套，本机配置和数据都会保留。每个 Skill 的文件夹里有它自己的说明页：

| Skill | 说明页 | 最快拿到结果 | 最少要准备 |
| --- | --- | --- | --- |
| `dei-capture` | [README](skills/dei-capture/README.md) | 「搜一下 YouTube 上关于 Claude Code 的入门教程」 | Python、yt-dlp，不用账号 |
| `dei-daily-report` | [README](skills/dei-daily-report/README.md) | 「给我今天的政策与商机日报」 | Python，不用账号 |
| `dei-notebook` | [README](skills/dei-notebook/README.md) | 「把这几个 YouTube 视频建成知识库」 | Python、Google 账号 |
| `dei-course` | [README](skills/dei-course/README.md) | 「帮我写一节教大家用 AI 写周报的课的手册」 | Python |
| `dei-moments` | [README](skills/dei-moments/README.md) | 「这是我的 3 条朋友圈，帮我做一份风格提示词」 | 什么都不用 |
| `dei-profile` | [README](skills/dei-profile/README.md) | 「我出门介绍自己总说不清，这是我的素材，帮我梳理」 | 什么都不用；出 PDF 要 Chrome |
| `dei-ppt` | [README](skills/dei-ppt/README.md) | 「这是我的课程手册和活动海报，按海报风格出一套讲课 PPT」 | 你的手册；Node.js + Python；Keynote 或 LibreOffice |

只装一个的命令（把 `dei-capture` 换成你要的）。和装 dbs 一样用 Skills CLI（需要 Node.js）：

```bash
npx -y skills add chenlongdei/deiskill --skill dei-capture
```

或者用一键安装，它会顺便检查环境，重装时备份旧版本、保留配置；`dei-daily-report` 的 AI 和知乎模块依赖上游工具，只有这种装法会一起拉取：

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash -s -- dei-capture
```

```powershell
$env:DEISKILL_ONLY="dei-capture"; irm https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.ps1 | iex
```

装完后，安装器会告诉你第一句可以对 Agent 说什么。

## 依赖、成本与许可

安装前先看清楚代价。下表没列到的都免费。不用提前装全：第一次用到某个功能时，Skill 会先自检，告诉你缺什么，并按你的系统给出一条安装命令，你同意后再装。

| 用到什么 | 需要准备 | 费用 | 不准备会怎样 |
| --- | --- | --- | --- |

## 安装细节

一键安装会把仓库放在 `~/.deiskill/repo`，再运行安装器。不想敲命令：把这个仓库的网址发给你的 Agent，说「帮我安装 deiskill，按 README 操作」。

也可以手动安装：

```bash
git clone https://github.com/chenlongdei/deiskill.git
cd deiskill
bash scripts/install.sh                 # 检测本机已有的 Agent；有多个时会问你装到哪些
bash scripts/install.sh dei-capture     # 只装指定的 Skill
bash scripts/install.sh --target ~/.claude/skills --target ~/.workbuddy/skills   # 指定目录
bash scripts/install.sh --list          # 查看全部 Skill
```

Windows 上把 `bash scripts/install.sh` 换成 `python scripts\install.py`，参数相同。

- **支持哪些 Agent**：安装器会自动识别 Claude Code（`~/.claude/skills`）、Codex（`~/.codex/skills`）、WorkBuddy（`~/.workbuddy/skills`）和 `~/.agents/skills`。其他支持 Skills 的 Agent，用 `--target <它的 skills 目录>` 指定；实在不行，把 `skills/` 下对应的文件夹整个复制进去也能用。
- **定时任务**：用系统自带的定时工具（macOS launchd、Windows 任务计划程序、Linux cron）直接运行脚本，和用哪个 Agent 无关，Agent 关着也照跑。macOS 上保存位置在外接盘、桌面或文稿时，第一次会提示你给 Python 开「完全磁盘访问权限」，并给出要添加的路径。
- **重装或升级时**，旧版本会备份到 `~/.deiskill/backups/<时间>/`，你的配置和运行数据会自动保留。
- 凭证只写进本机的 `config.json`，不进 Git。各 Skill 的 `config.example.json` 列出了全部配置项。

## 结果存在哪里

所有 Skill 共用一个「dei 工作区」。第一次用任何一个 Skill 时，它会给出 2—3 个建议位置，你确认后才创建，以后不再问。报告和数据都放在这里，不放进 Agent 的安装目录：

```text
dei工作区/
├── 使用说明.md
├── 01_我的清单/   你自己维护的表：抖音监控工作簿、选题表
├── 02_采集/       YouTube、抖音博主和关键词巡检、音视频转写
├── 03_日报/       综合日报（按年）、政策与商机、AI 情报、知乎热榜
├── 04_知识库/     一个主题一个文件夹：问答、学习路线
├── 05_成品/       课程、朋友圈、准备发布的内容
└── 99_系统/       运行总账、日志、备份、试跑结果（平时不用看）
```

- **怎么命名**：一次性的结果按「日期_时间_主题」命名（北京时间），比如 `2026-11-13_1600_Claude-Code入门`；长期跟踪的博主、频道、知识库按名字命名。
- **找最近的产出**：每次运行都会在 `99_系统/运行总账.jsonl` 记一行，直接问 Agent「最近一次日报在哪」「上次关键词巡检的结果呢」就行。
- **试跑和正式分开**：试跑和测试的结果一律放进 `99_系统/测试/`；临时缓存 30 天后自动清理。
- **外接盘没插**：会直接报错，不会悄悄写到别处。
- **从旧版升级**：`python3 scripts/migrate_workspace.py --skills-dir <skills 目录> --to <新工作区>` 先预览要搬哪些文件，加 `--apply` 才真正搬，搬完可以撤回。

# Claude Code 实操手册｜不会写代码，也能让它替你把活干完

> **一句话说清：** 内容创作者、运营、老师，看完能用大白话指挥 Claude Code 做出小工具、整理素材、清洗表格，并让它记住你的规矩。

**你不需要懂任何技术。你只需要会：说清楚要什么、复制、粘贴、检查结果。**

---

## 先看结果：用它能做成什么

- 一个双击就能打开的课堂点名器，名字滚动 2 秒后停下，还会放彩带。
- 几百个乱放的截图、文案、视频，自动归进「年份-月份 / 主题」的文件夹。
- 十几份格式不一的报名问卷，合成一张干净的名单表，并附一段统计总结。
- 一个「小红书文案助手」：以后只说一句「写篇护手霜种草」，它就按你定的格式出稿。
- 一张手绘草图或网页截图，变成手机上也能看的展示页。

这些都不用你写一行代码。你要做的，是把需求说清楚，然后检查它做得对不对。

---

## 准备：10 分钟装好，做出第一个小东西

1. **装软件**：不碰命令行的，装桌面版（官网下载，像装微信一样）；用得惯命令行的，装终端版。都需要 Claude 付费订阅。
2. **建一个空文件夹**，比如桌面上的「我的第一个工具」。把它想成 Claude 的专用工作台：它只在这个文件夹里干活。
3. **在 Claude Code 里打开这个文件夹**，它问「是否信任这个文件夹」时选「信任」。
4. **复制下面任务 1 的那段话发给它**，看它干活。
5. 它做完后，双击生成的网页文件，在浏览器里试一试。

> ⚠️ 刚开始别打开「跳过所有确认」。先让它每一步都问你，看懂它在干什么，再慢慢放手。

**认识三个按键，够你用一个月：**

| 按键 | 作用 | 打个比方 |
| --- | --- | --- |
| `Esc` | 立刻让它停下 | 喊「停」 |
| 连按两下 `Esc` | 回到之前某一步，撤销它改过的东西 | 后悔药 |
| `Shift + Tab` | 切换「每步都问我」和「改文件不用问我」 | 放手的程度 |

## 任务

每条指令都是三段：**给什么材料 → 做什么、做成什么样 → 不能破的规矩**。第三段最重要，它防止 AI 乱改、乱编。

### 任务 1：做一个双击就能用的小工具

做完你会得到：一个网页文件，双击在浏览器打开，断网也能用。

👆 复制这段话发给它：

```text
【材料】没有材料，从零开始，就在当前文件夹里做。
【要做什么】做一个「课堂随机点名器」网页：左边一个大文本框，用来粘贴全班名单；右边一个醒目的「抽取幸运同学」按钮。点按钮后，名字快速滚动 2 秒，最后停在一个名字上，弹出彩带动画。界面干净可爱。
【规矩】所有东西放在一个网页文件里，不需要我安装任何东西。做完告诉我文件名和怎么打开。
```

**怎么算成功**：文件夹里多了一个网页文件；双击打开，粘贴名单、点按钮，能看到滚动和彩带。

**翻车了怎么救**：
- 打开是空白，或者按钮点了没反应 → 截图拖进对话框，说「我打开后是这样，按钮没反应，帮我找出原因并修好」。
- 样子不好看 → 别说技术词，直接说你看到的：「标题太小，放大一倍并居中；底色换成奶黄色；按钮做大做圆」。

出处：Teacher's Tech《Desktop App: Beginner's Guide》、Futurepedia《Full Tutorial for Non-Technical Beginners》

### 任务 2：整理一堆乱放的素材

做完你会得到：截图、文案、视频按类型和日期归进清楚的子文件夹。

👆 复制这段话发给它：

```text
【材料】当前文件夹里的所有文件。
【要做什么】先不要移动任何东西。列一份整理计划：哪些是图片、哪些是文案、哪些是视频，你打算放进哪些文件夹、文件夹叫什么名字。我回复「同意」后再开始整理。
【规矩】只动图片、文档、视频这几类素材文件，其他文件原地不动。遇到重名文件不准覆盖，在名字后面加 _01、_02 分别保留。不准删除任何文件。
```

**怎么算成功**：它先给你一张计划清单，不会直接动手；你同意后，文件夹变整齐，文件总数和整理前一样。

**翻车了怎么救**：
- 有文件不见了 → 马上按 `Esc` 停下，再连按两下 `Esc` 回到整理前。然后把「不准覆盖、不准删除」那句规矩加粗再发一次。
- 分类不合你心意 → 在它给计划时就改：「视频按拍摄月份分，不按主题分」。

出处：Greg Baugues《47 PRO TIPS》、Grace Leung《Build Your First AI Agent》

### 任务 3：把几份乱表格合成一张干净的表

做完你会得到：一张对齐、去重的汇总表，加一段统计总结。

👆 复制这段话发给它：

```text
【材料】当前文件夹里所有的报名问卷文件。
【要做什么】提取「姓名、联系方式、报名课程、付款状态」四列，去掉重复提交的记录，汇总成一张「最终名单汇总」表格（Excel 能打开）。最后用 200 字写清：一共多少人报名，哪门课最受欢迎。
【规矩】材料里没有的数字不准编，缺的格子空着并标「缺」。打不开或格式残缺的文件跳过，单独列出来告诉我。做完自己核对一遍：汇总表的人数，等于原始文件去重后的人数，把核对结果告诉我。
```

**怎么算成功**：表格能用 Excel 打开，没有乱码；它报告的核对结果对得上。

**翻车了怎么救**：
- 数字对不上 → 说「把每个数字标清楚：是原文件里的，还是你算出来的（写出算式），还是找不到出处」。找不到出处的，就是它编的。
- 读到一半卡住 → 说「坏文件直接跳过，先合并能读的，最后告诉我跳过了哪些」。

出处：Simon Scrapes《How the Top 1% Use Claude Code Differently》、Anthropic 官方《Building headless automation》

### 任务 4：照着草图或截图做页面

做完你会得到：一个和你的草图排版差不多的网页，手机上也能看。

👆 把图片拖进对话框（Mac 上粘贴截图要按 `Ctrl + V`，不是 `Command + V`），再发这段话：

```text
【材料】我刚拖进来的这张活动海报草图。
【要做什么】看清图里有哪几块、主色调、标题和正文的大小关系，做一个排版一致的网页。图里的文字原样搬进去。
【规矩】手机宽度下不能出现文字重叠或横向滚动。做完告诉我怎么打开。
```

**怎么算成功**：浏览器里打开，板块位置和草图基本一致；把浏览器窗口拉窄，排版不乱。

**翻车了怎么救**：
- 和原图差很多 → 把它做出来的页面截图，和原图一起拖进去：「对比这两张图，大图位置偏了，按钮颜色太深，以原图为准改」。
- 截图贴不进去 → Mac 上用 `Ctrl + V`，或者直接把图片文件拖进窗口。

出处：马克的技术工作坊《从 0 到 1 全攻略》、Sajjaad Khader《Learn 80% of Claude Code》

### 任务 5：让它记住你是谁、你的规矩

做完你会得到：一份「项目说明」。以后每次打开这个文件夹，它都自动按你的要求来，不用每次重新交代。

> 打个比方：项目说明是贴在工作台上的「注意事项」，它每次开工前都会先看一眼。所以要短，只写它猜不到的事。

👆 复制这段话发给它：

```text
【材料】当前文件夹里的内容。
【要做什么】帮我生成项目说明文件。要它记住：我是高中语文老师，这个文件夹放期末复习讲义；回复要通俗活泼，不用技术行话；重点内容加粗。
【规矩】用中文写，30 行以内，只写你自己猜不到的事，不写空话。
```

**怎么算成功**：文件夹里多了一个叫 CLAUDE.md 的文件；新开一个对话问它问题，它的口吻和格式符合你的要求。

**翻车了怎么救**：
- 写成了一大篇英文技术说明 → 说「删掉所有技术内容，压到 30 行以内，全部用中文写我的角色和排版要求」。
- 第二天它好像忘了 → 先确认打开的是原来那个文件夹。项目说明是跟着文件夹走的。

出处：Simon Scrapes、ByteByteAI《12 Features》、AI with Avthar《How I Start EVERY Project》

### 任务 6：做一个随叫随到的专属助手（技能）

做完你会得到：一个「小红书文案助手」。以后说一句「用小红书助手写篇护手霜种草」，它就按你定的格式出稿。

> 打个比方：项目说明是「注意事项」，每次都看；技能是「操作手册」，用到哪本才翻哪本。一件事你反复交代三次以上，就该做成技能。

👆 复制这段话发给它：

```text
【材料】下面是我对小红书文案的要求。
【要做什么】帮我创建一个叫「小红书种草助手」的技能：每次给 3 个备选标题；正文每段不超过两句，穿插贴切的表情；文末附 5 个话题标签。写好触发说明，告诉我以后怎么叫它。
【规矩】禁止「在当今快节奏的社会」「总而言之」这类 AI 套话。只有我明确叫这个助手时才用，平时聊天不要套这个格式。不要让我手动填任何代码。
```

**怎么算成功**：你说「用小红书助手写一篇护手霜种草」，它提示用上了这个技能，出稿符合三条要求。

**翻车了怎么救**：
- 平时聊天它也套用这个格式 → 说「改一下这个技能，只有我点名叫它时才用」。
- 文案 AI 味重 → 把你不想看到的词直接列给它，让它写进技能的规矩里。

出处：马克的技术工作坊、JavaScript Mastery《Full Course 2026》、Matt Kuda《Skills, MCP, Agents & Plugins》

### 任务 7：请一个只挑错、不动手的审查员

做完你会得到：一个专门挑错的帮手。它在旁边单独干活，查完只交给你一张「原句 → 建议」对照表，不改你的原文。

> 打个比方：它像外请的校对，在隔壁房间看稿，看完只递给你一张纸条。好处是不占用你和 Claude 主对话的「记忆空间」。

👆 复制这段话发给它：

```text
【材料】无，先把审查员建好。
【要做什么】帮我创建一个专门审查错别字、标点和广告违禁词的子代理。审查完只交给我一张「原句｜问题｜修改建议」对照表。
【规矩】它只能读文件，不能修改任何文件。
```

然后对它说：「让审查员看一下《活动通知》这份文件。」

**怎么算成功**：你能看到一个单独的审查员在跑；最后主窗口只出现一张对照表，原文件没被改动。

**翻车了怎么救**：
- 它把原文改了 → 连按两下 `Esc` 撤回，然后说「把审查员改成只能读、不能写」。
- 太慢、太费额度 → 说「审查员换成最快的轻量模型，每次只看我指定的那一篇」。

出处：Developers Digest《Sub Agents in 7 Minutes》、马克的技术工作坊、JavaScript Mastery

### 任务 8：给重要文件装一个「自动备份」

做完你会得到：每次它改文件之前，自动把旧版本存一份到 backup 文件夹。改坏了，随时能找回。

> 打个比方：这是装在门口的自动摄像头，不用提醒，每次都会拍。你在项目说明里写「记得备份」，它偶尔会忘；做成自动规则，它就一次都不会漏。

👆 复制这段话发给它：

```text
【材料】当前文件夹。
【要做什么】帮我设置一条自动规则：每次你修改或新建文件之前，先把原文件复制一份到 backup 文件夹，文件名加上日期时间。设置好后改一个文件试给我看。
【规矩】备份失败时不要卡住我们的正常对话，只提醒我一句。不要让我手动填配置。
```

**怎么算成功**：让它随便改一段文字，然后打开 backup 文件夹，能看到修改前的那一份。

**翻车了怎么救**：
- 每次改完都弹一串红字 → 把红字截图发给它：「这条自动规则报错了，改成用最简单的复制方法，失败也别卡住」。
- 文件夹被备份塞满 → 说「只保留每个文件最近 5 份备份」。

出处：Anthropic 官方《Hooks in Claude Code》、马克的技术工作坊

## 看看别人怎么玩

工具会换，思路不变：把需求说清楚，定好规矩，让它干活，你只负责验收。

| 谁 | 做了什么 | 怎么跟它说的 | 做出了什么 | 你可以怎么照搬 |
| --- | --- | --- | --- | --- |
| Teacher's Tech（老师） | 课堂随机点名器 | 先说「输入名单、点按钮随机选人、带动效」；做好后再说「改成轮盘那样快转 2 秒逐渐减速」；最后点中页面上的按钮，让它换成柔和的蓝绿色，加一个「再抽一次」 | 单个网页文件，任何电脑双击就能用 | 换成抽奖、分组、倒计时，同一个思路 |
| Futurepedia | 立体魔方井字棋小游戏 | 先描述规则让它出计划，看完计划再让它动手；之后一句句加功能：人机对战、三档难度、胜利划线 | 能在浏览器里玩、能上线给别人玩的游戏 | 第一句只说清「玩法」，功能一次加一个 |
| Grace Leung（内容创作者） | 长视频文案自动变成社媒轮播图 | 先把品牌资料（官网、配色、历史高赞帖）放进文件夹写进项目说明；再做一个「排版技能」；每次她改了审美（比如「不要棕色背景」），就让它把这条记进一份「反馈记忆」 | 每晚自动从 Notion 读待办素材，出图后放回看板等她审核 | 先把你每次都要改的审美意见攒成一份清单，再交给它 |
| Futurepedia | 会议纪要自动变成任务分配 | 连上会议录音工具和任务看板，说「从最新的会议纪要里提取待办，按团队成员的分工分给对应的人」 | 一个能拖拽分配、自动同步到看板的任务界面 | 换成「从群聊记录里提取待办」 |
| JavaScript Mastery | 完整的电商网站 | 先写好规矩（不准读密码文件、设计风格参照高端品牌、不准用紫色渐变），再让它分步做；最后派 5 个审查员分别检查不同部分 | 能真实下单付款的网站 | 规矩先行：先说「不准做什么」，再说「做什么」 |
| Anthropic 官方 | Issue 自动变成代码改动 | 在项目的需求单下面留言「@claude 请实现这个功能」 | 它自己读需求、改代码、跑测试、提交改动等人审核 | 偏技术，先了解，等用熟了再学 |

**共同点**：没有一个人是一句话就做出成品的。都是先说清目标，再一次改一个地方，每次改完都亲眼检查一遍。

## 常见问题

| 你遇到的 | 为什么 | 怎么办 |
| --- | --- | --- |
| 它停不下来，屏幕一直滚 | 它还在执行上一个指令 | 按 `Esc` |
| 每改一个字都问我同不同意，太烦 | 默认是最谨慎的模式 | 按 `Shift + Tab` 切到「改文件不用问我」；或在询问时选「本次对话都允许」 |
| 聊久了它变笨，忘了前面说过的 | 对话太长，它的「记忆空间」装满了 | 先让它「用 200 字总结目前进展和下一步」，复制下来；输入 `/clear` 清空，再把总结贴回去 |
| 改坏了，想回到之前 | — | 连按两下 `Esc`，选择要回到的那一步。重要文件建议先装任务 8 的自动备份 |
| 提示额度用完，要等几小时 | 订阅额度按时间段刷新 | 等它刷新；日常小事输入 `/model` 换成更轻的模型，省额度 |
| 重新打开后说找不到原来的文件 | 打开的不是原来那个文件夹 | 重新打开原来的项目文件夹；想接着上次的对话，在会话记录里选上次那一条 |
| 我说「不准动某个文件」，它还是动了 | 嘴上的规矩，它偶尔会忘 | 让它「把这条做成硬性限制，不是写在说明里」，做法同任务 8 的思路 |

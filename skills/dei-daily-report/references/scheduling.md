# 统一调度

仅在用户请求实际创建或调整定时时使用。调度器唤醒 Codex，由总入口读取并执行选中的子skill；skill文件本身不会注册定时器。

使用 Codex automation_update 工具，默认当前任务heartbeat。独立项目定时只有用户明确要求时用cron，并先用list_projects确认真实项目ID。检查 $CODEX_HOME/automations/*/automation.toml（变量未设则 ~/.codex/automations/）已有名称、提示和状态，优先更新避免重复。保留未要求修改的字段与通知偏好。

区分新增综合入口与统一替换旧调度。替换时记录原ID和配置，仅迁移用户明确涵盖的渠道；范围不清楚时先确认替换哪些，不暂停旧任务。子skill首次引导、频率建议和历史预约文字不授权创建第二套调度；真实任务状态以保存配置和工具结果为准。

时间按Asia/Shanghai，以用户时刻及频率为准。知乎当前快照的抓取时刻会随统一启动时间改变，不承诺同时保留过去不同渠道的精确时刻。完成、失败、部分完成或需处理时通知；重复检查无变化且无可行动事项时保持安静。保留用户静音偏好。

## 综合晨报提示

> 使用 $dei-daily-report，入口 <本 Skill 安装目录>/SKILL.md，生成全平台日报，选择 policy、ai、zhihu、douyin，使用各模块默认窗口。完整执行选中子skill，保存综合稿与运行记录，附子产物链接。单模块失败继续其它模块，明确部分完成及缺口。仅在当前任务交付；完成、失败或需处理时通知，重复检查无变化时保持安静。不要创建或修改子调度器。

## 按领域提示

> 使用 $dei-daily-report，入口 <本 Skill 安装目录>/SKILL.md，只执行 ai、policy，使用默认窗口。完整执行子skill，保存统一入口稿、运行记录和子报告链接，明确覆盖与完成状态。仅在当前任务交付；完成、失败或需处理时通知，重复检查无变化时保持安静。不要运行其它模块或更改调度。

保存提示时把 `<本 Skill 安装目录>` 换成实际绝对路径；提示必须带真实入口路径、模块与窗口，避免依赖隐含上下文。不把私人任务ID写入可分享skill。运行所需网络、登录和余额依各子skill检查，失败写入本次运行记录。

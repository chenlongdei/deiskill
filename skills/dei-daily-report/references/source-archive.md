# 头条原文存档

每期对外日报的「今天最重要的一件事」，把它涉及的官方原文、附件、解读抓下来存档，用来核对日报里的日期、文号和数字，也给社群成员作为延伸阅读。

## 流程

1. **识别文件**：政策文件（注意文号）、发布会或吹风会、官方解读和答记者问、日报提到的前序文件和上位依据。日报里"接下来要看、待出台"的文件不抓，核实确实还没发布后列入跟踪清单。头条是 AI 或社会话题时，对应的是公司公告、招股书、官方博客、监管文件等一手材料。
2. **检索官方链接**：发文机关官网（gov.cn、部委官网）> 新华社、人民日报 > 国新办 > 中新网等央媒 > 地方政府、行业协会转载。每份文件至少一个官方链接，用"文件全称 + 文号 + 站点限定"检索，警惕自媒体转述。写成运行目录下的 `_原始数据/头条原文.json`（格式见 `archive/archive_sources.py` 开头）。
3. **三层降级抓取**：① 直连（浏览器 User-Agent）② 浏览器渲染（应对加密 JS、cookie 挑战页）③ 换源（实录类页面常为 JS 分页加载，改抓单篇发言页、国新办或新华社通稿，多源拼合并注明）。
4. **关键句验证**：每篇取 2—3 个关键句（文号、核心条款、施行日期）在正文里核对，缺失就重抓或换源，绝不交付没验证过的正文。
5. **存档**：每份文件一个 **PDF**，文件名 `序号_文件标题（文号）.pdf`；文档头部四行：标题 / 来源（网站 · 日期）/ 原文链接 / 抓取日期；正文全文不改写删节。附 `00_总览与链接索引.pdf`：名称、文号、发文机关、成文与发布日期、施行日期、要点、存档文件名、官方链接，以及待出台文件跟踪清单。

## 输出位置

`<运行目录>/原文存档/`：`pdf/`（全部 PDF）、`html/`（原始网页，被拦截页也保留并注明）、`md/`（正文中间稿）、`链接总览.md`（链接速查和抓取备注：哪些站被拦截、怎么绕的）。

## 注意

- 日期、文号、数字以原文为准，发现日报写错就改日报。
- 媒体解读不等于原文，可以收录但单独标注性质，不冒充原文。
- 抓不到就明说卡在哪一层，不拿摘要凑数；存档缺口属于不进成品的内容，单独告诉用户。

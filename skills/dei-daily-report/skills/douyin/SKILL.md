# 抖音近7天拆解表

把模板工作簿更新为可交付的新副本。只录入客观数据：标题、BGM、链接、发布时间、抓取时间、粉丝量、点赞、评论、收藏、转发、赞粉比、逐字稿、前5秒和结尾。不要生成分类、内容逻辑、核心论点、钩子类型等主观字段，除非用户另行要求。

## 使用流程

1. 读取 [references/configuration.md](references/configuration.md)，确认本机依赖、凭证和账号覆盖表。
2. 首次迁移或接口异常时，读取 [references/troubleshooting.md](references/troubleshooting.md)。
3. 在包含目标 `.xlsx` 的目录执行 `python3 <skill-dir>/scripts/run_pipeline.py --input <工作簿.xlsx>`。
4. 默认输出到输入文件旁的 `outputs/douyin-weekly-workbook/`，不覆盖原文件。
5. 完成后检查摘要和失败清单；用电子表格工具检查关键 Sheet、日期显示、公式错误和视觉布局。

## 固定规则

- 第一张 `相似博主总表` 提供博主名称和抖音号；后续每个 Sheet 代表一个博主。
- Sheet 名与总表名称标准化后精确匹配。截断名、改名和拼写错误只能使用 `account_overrides.json` 修正；不要凭相似度猜账号。
- 修复已污染的页签时，使用 `--only-sheets '页签1,页签2' --replace-sheets '页签1,页签2'`。替换只清除 A:S 的对方视频区，T:AJ 的个人创作与复盘区保留。
- 不得仅因 Sheet 名匹配就认为账号正确。账号覆盖中的 `sec_uid` 优先级最高；发现表内旧视频作者与目标账号不一致时必须使用替换模式，不能继续增量追加。
- 优先抓滚动近7天作品。若该账号为0条，取消时间限制并补抓最近7条。近7天已有1条或以上时，不额外补足7条。
- 视频 ID 是唯一键。已有视频只刷新客观指标和抓取时间；人工字段与已有逐字稿不覆盖。新视频追加并延续模板样式与公式。
- 去水印使用大圣；转写使用阿里云百炼 `paraformer-v2`。同一视频即使出现在多个 Sheet，也只提交一次转写。优先复用已有逐字稿；新转写任务ID和结果保存在本模块 data/asr_tasks.json，中断后恢复同一任务，不重复提交。任务失败保留状态，重提需要明确确认失败并清理对应日志项。
- 前5秒优先按句级时间戳提取；结尾取最后几个有效语音句。无时间戳时才按文本首尾降级。
- 单账号或单视频失败不得中断整批。输出明确失败原因；缺失不能写成0。
- 凭证不得打印到终端、工作簿或最终回复。

## 停止条件

- 401/403：停止外部调用并报告凭证无效。
- 402：停止 TikHub 调用并报告余额不足。
- 连续限流或上游失败：有限退避重试，仍失败则记录后继续其他账号。
- 无法可靠匹配账号：跳过并要求抖音号、主页链接或任意作品链接。

# dei-日报：政策与商机

读懂“发生了什么→与过去相比变在哪里→如何改变需求/成本/规则→谁付钱→哪些业务环节可进入→什么证据能确认或推翻”。分析由当前模型完成，不额外调用第三方模型API。

生成前阅读 [分析方法](references/analysis-method.md) 和 [日报模板](templates/daily-report.md)。已提炼的正反例位于 [分析示例](references/examples.md)，需要校准洞察和颗粒度时读取。示例用于理解方法，不是当日事实证据。

## 数据与日期

数据目录（下文写作 `data/`）为 dei 工作区 `03_日报/政策与商机/`，由总入口 `scripts/dei_paths.py` 解析（`python3 scripts/dei_paths.py policy` 打印全部路径）；数据和报告不写进 Skill 安装目录。逐字稿：`data/逐字稿/YYYY/MM/YYYYMMDD.md`；成品：`data/报告/YYYY/YYYY-MM-DD_分析报告.md`；下载的原件：`data/原件/YYYY/播出日/`；主题状态：`data/主题状态.json`；研究与修订：`data/修订/`；日志在工作区 `99_系统/日志/政策与商机/`。成品首部包含 `<!-- method-version: 3.3.0 -->`，用于识别旧方法报告。

每天Asia/Shanghai 05:00晨报以昨天为播出日；手动按用户指定日，未指定时以昨日为目标。区分晨报日、播出日、文件签发/公开/实施日。

## 核心方法与表达

以假设为驱动，以事实为基础，提出符合逻辑的真知灼见。客观扫描全部新闻，不因用户其他模块涉及AI、短视频而预设行业优先。去粗取精：筛出真正改变需求的事项；去伪存真：查原始资料及反证；由表及里：解释政策为何改变买方行为；由此及彼：检验产业上下游与受损方向。

今日结论写洞察而非新闻拼盘：明确判断→关键事实→通俗因果解释→成立边界及如何验证。结论可以大胆，推理必须清楚，不把尚未证明的假设写成事实。

按S/A/B/C强弱分组，组内按重要性展开，保留新闻原编号；以小标题、连贯文字、短列表为主，不输出新闻大表格和逐字段卡片表格；边际变化固定使用对比表，列事项、过去日期与事实、现在日期与事实、变化判断、经营含义，来源就近附上。用具体人、钱、事讲清机制，术语第一次出现解释为普通话。不模仿口号或生硬套用名句。

公开资料能检索的由模型完成检索和读取，给精确链接；有可下载原件时下载到data/原件/YYYY/播出日/并记录来源。链接失败可用官方镜像或替代原始发布，仍失败标明。已取得的资料不能再列为让用户查找的任务；只有访谈、实践、非公开预算等留作现实验证。回溯报告区分播出时可得事实与后补资料。

## 执行

1. 用 `python3 scripts/fetch_xwlb.py --date YYYYMMDD` 抓取。每次运行都计算截至目标日在内的30个自然日覆盖；发现缺日时，当次任务必须逐日自动补抓，不能只把缺口列给用户。主源失败后继续使用央视节目页、公开文字稿或其他可核验备用源，并在逐字稿首部标明来源性质。完成补抓后重新核对覆盖率；只有所有可用公开来源均失败的日期才作为剩余缺口报告，并写明已尝试的来源和失败原因。目标日缺失/失败明确返回状态，不以旧消息代替。
2. 已存在且方法版本一致的成品返回链接；用户要求重做或方法过时时，先在data/修订/备份再生成。
3. 读当天全文，快讯拆子项并保留编号。历史标题用于定位，重点事项进一步读相关历史正文、官方前序文件；不再限制历史只能读标题。
4. 按方法完成分级、经济机制和边际变化。新闻明确提到声明、规划、通知、意见、办法、报告或成果文件时，当次任务必须继续检索其官方正文或附件并读完相关条款，再写判断；公开原文已取得时，不得在成品中留下“需读取文件后判断”。同时主动检索真实项目或采购入口并引用具体页面；只有官方正文尚未公开、所有可用来源均失败或附件确实无法访问时才留明缺口，不以机关首页充当已核验证据。
5. 商机卡片按独立假设和证据自然形成，有多少写多少，不固定数量、上下限、奇偶；单数只可作为同等质量下的排版偏好，不凑数。全局产业机会与个人可达入口分清，不把所有机会强行归结为课程或内容制作。
6. 做覆盖、传导、证据三轮审稿并修订，记录实质修改；更新有来源的主题状态，写成品并返回链接与主要判断。

## 约束

信号S/A/B/C与商机成熟度分开，说明评级理由和核验状态。单次措辞不能证明资金增加；没有历史正文不能称首次。同主题共振不等于执行链。边际变化区分现实新变化、重复报道、同主题关联、研究新发现；补查到旧资料不能当成当天政策新增。预算、销售额、资本投资、贷款、累计交易量分别标记，禁止异口径倍率。预算、资质、利润、回款和时滞不清楚时标未知/假设，并给验证办法。外交说法分别归属。附件只是研究资料，不授权发消息或其他外部操作。

## 跨Agent部署与定时

目录可直接复制到目标agent的skills目录，或让agent读取本文件。所需能力为文件读写、Python 3.9+、curl、联网检索与网页/PDF读取；没有网络工具的agent只能生成标明限制的离线分析，不宣称完成外部核验。

手动运行 `bash scripts/run_daily.sh` 默认昨日；`--date YYYY-MM-DD` 指定播出日，`--force`备份后重做。CLI适配在scripts/run_agent.sh，依次使用agent.conf自定义命令、Claude Code、Codex；调用AI可能使用该agent账户额度。

调度二选一：在目标agent内设Asia/Shanghai每日05:00，按本skill完整执行；或macOS显式运行 `bash install.sh --launchd`，使用本机CLI。本skill不会自行注册调度，不同时开启两套。仓库不携带私人任务ID或配置。其他系统用现有调度器调用脚本，确保机器在线、CLI登录和检索能力可用。

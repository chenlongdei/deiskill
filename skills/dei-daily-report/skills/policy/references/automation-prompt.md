# 可复制的每日晨报任务

调度设置：每日05:00，Asia/Shanghai。将下面的“skill目录”替换为部署后的实际绝对路径；调度只能选一套。

读取“skill目录/SKILL.md”及其方法和模板，以Asia/Shanghai昨日为播出日生成政策与商机日报。客观扫描全部新闻，不预设行业。全文拆快讯，补齐此前30自然日历史，重点深读正文和前序官方文件。以假设为驱动、事实为基础，检索支持与反证，形成有通俗因果解释的洞察。公开文件由你检索读取，准确链接或下载原件交付，不把已取得资料再留给用户查找。按S/A/B/C展开文字，边际变化五列表格；分清现实变化、重复报道、主题关联和研究更新。商机数量自然形成，合并同买方同交付分支，解释付费、成本回款、门槛、渠道及停止条件。更新稳定主题与假设，记录本次证据如何改变原判断。审稿修订，报告包含当前方法版本标记，写入data/报告/YYYY/播出日_分析报告.md（data 为 dei 工作区 03_日报/政策与商机/），返回绝对路径和简短洞察。目标日缺失或失败明确通知，不以旧消息冒充。已存在同版报告返回链接；旧版重做先备份。不自行创建其他调度或发送外部消息。新报告完成、失败、需用户处理时通知，状态不变保持安静。

# dei-moments · 朋友圈私域

**让 AI 写出像你本人的朋友圈，知道每天该发什么；卖东西时一浪一浪地发，发完复盘，把这一期的结果变成下一期的案例。**

它是 [deiskill](https://github.com/chenlongdei/deiskill) 的一部分，也可以单独装、单独用。不用任何账号和配置。

## 最快拿到第一个结果

装好后对你的 Agent 说：

> 这是我最近发的 3 条朋友圈，帮我做一份风格提示词：<粘贴>

它会从你写过的字里反推出你的说话方式，每一条特征都附上你的原话当证据。以后写任何文案都先用它，读起来才像你本人。语料越多越准：按住说话讲讲你的一天、几段聊天记录（先遮掉客户名字）、公众号文章都可以。

## 安装

**和装其他 Skill 一样**（需要 Node.js）：

```bash
npx -y skills add chenlongdei/deiskill --skill dei-moments
```

**或者用一键安装**，它会顺便检查环境，重装时备份旧版本、保留你的配置：

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash -s -- dei-moments
```

Windows PowerShell（需要先装好 git 和 Python 3.9+）：

```powershell
$env:DEISKILL_ONLY="dei-moments"; irm https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.ps1 | iex
```

不想敲命令：把这个页面的网址发给你的 Agent，说「帮我安装 `dei-moments`，按 README 操作」。

它会自动识别 Claude Code、Codex、WorkBuddy 等 Agent 的 skills 目录；装好后重启 Agent。以后想要整套能力，装 [deiskill 全套](https://github.com/chenlongdei/deiskill)即可，本机配置和数据都会保留。

## 它能做什么

| 你说 | 你会拿到 |
| --- | --- |
| 「这条朋友圈为什么没人理」 | 逐条诊断为什么没人停下来，原文里哪些好东西要留下，往哪改 |
| 「帮我排这次发售的朋友圈」 | 浪潮式发售方案：哪几天只讲故事不卖、哪天是截止的浪头、每天发几条；前几天的文案和私聊开场；一张私下记数据的表 |
| 「每天不知道发什么」 | 一周排期，个人、专业、产品按比例搭配 |
| 「这个产品写不出东西了」 | 卖点 × 角度的选题矩阵，约 40 个切入点，可以扩到 100 条 |
| 「这条火了，还能怎么用」 | 短视频选题、口播脚本、公众号提纲 |
| 「发售结束了，帮我复盘」 | 复盘结论；真实的学员原话和数据写进素材库，留给下一期 |

## 用的是什么方法

来自一次真实课程发售的诊断、改写和排期，加上十张运营表整理成的七模块方法：

- **开头两行决定生死**：朋友圈会折叠，开头必须是冲突、真实的数字或一句原话。
- **每条都要有增量**：读者看完要白拿走一样东西，只完成任务、没有增量的稿子不交。
- **主角是你自己**：每条至少一个只有你讲得出来的细节。
- **从「读者掏钱之前在问什么」倒推每天发什么**，不机械拆你原来的文案。
- **浪潮式发售**：概念出自杰夫·沃克《浪潮式发售》。
- **不编**：数字、客户原话、截图、剩余名额只用你给的真实内容；缺的地方留【这里放：××】让你补。说只剩 3 个，就得真的只剩 3 个。

## 结果存在哪里

第一次用时，它会问你「dei 工作区」放在哪里，你确认后才创建。风格提示词、素材库、每期发售方案都在工作区的 `05_成品/朋友圈/` 下，只存在你自己的电脑上。

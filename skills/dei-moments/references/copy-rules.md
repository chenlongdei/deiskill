# 朋友圈文案：写法和诊断

> 写任何一条朋友圈前读第一、二节；诊断一条没回响的朋友圈时读第三节。

## 一、一条好朋友圈的结构

**判据：读者为什么要停下来、为什么要看完、看完白拿走了什么。**

1. **开头两行**：冲突、真实的数字、或者一句原话。别用质问句加外部数据开头，那是公众号和广告的写法，熟人刷到会直接划走
2. **主角是你自己**：至少一个只有你讲得出来的细节（一个地名、一个人、你自己的一个数、你踩过的一个坑）
3. **一个增量**：一个能对号入座的判断、一招当场能用的方法、或一个真实的变化
4. **结尾**：要么留个问题让人想看下一条，要么一句立场；卖东西的那几天，才是一句行动

**数据好的朋友圈常见的样子**：自己的一段经历 → 两三个和主流说法不一样、但来自亲身经历的判断 → 一句立场。全程不卖东西。

### 干货要有分量

- 太简单、AI 自己就能给出来的东西（比如一份三句话的提示词模板），读者感觉不到价值
- 好的干货是一个读者**当场就能做、做完会有发现**的动作。例如：「按住说话，把你一天的工作从早讲到晚，再让 AI 挑出哪些是重复的、按省时间排序」——做完他会自己看到问题，而且这个问题正好是你的产品要解决的
- 抽象的说法（「找到 AI 的第一份工作」）读者听不懂；换成具体场景

## 二、AI 写的稿，发之前过一遍

### AI 味检查表

- [ ] 有「家人们」「宝子们」「姐妹们」这类称呼（用户自己语料里这么说的除外）
- [ ] 一句一个表情
- [ ] 排比句、对仗句很多
- [ ] 结尾强行升华，像在灌鸡汤
- [ ] 有用户平时根本不会说的词
- [ ] 全是感受，没有一个具体的人、事、地方
- [ ] 「震惊」「像神一样」「绝对不会过时」这类夸张词

### 自查指令（给 AI 或自己用）

```text
逐条检查这几条朋友圈：
里面每一个数字、每一句「客户说」，标出它是来自我给的材料，还是你自己编的。
编的，直接删掉，换成【这里放：××】。
```

### 写作时给 AI 的统一格式

```text
【我是谁】风格提示词（见 style-prompt.md）
【我怎么说话】我自己写的 3 条朋友圈原文
【我卖什么】产品一句话 + 价格 + 适合谁
【这条的任务】用哪个模板，起什么作用（建信任 / 立专业 / 促成交 / 引流）
【素材】今天发生的事、照片里有什么、客户原话（已打码）
【禁忌】不用「家人们」，不堆表情，不灌鸡汤，不编数字和证言
```

## 三、诊断：为什么发出去没回响

先说明看不到的东西：发出时间、好友构成、之前几天发过什么、海报。然后逐项检查：

| # | 检查项 | 常见表现 |
| --- | --- | --- |
| 1 | **一条干了几件事** | 痛点、数据、背书、故事、产品、赠品、大纲、退款承诺、行动号召全塞一条；几百字被折叠，最好的东西埋在后面没人看到 |
| 2 | **开头像谁在说话** | 质问 + 百分比 + 「全球最大的××平台」：像广告，不像熟人 |
| 3 | **说给谁听** | 开头默认读者是某类人（比如「天天折腾智能体的人」），不是这类的人会觉得与己无关 |
| 4 | **证据是转述还是证据** | 「90% 的人」「学员普遍说」是转述；截图和原话才是证据 |
| 5 | **铺垫只有观点吗** | 之前几天只发观点：读者知道你怎么想，不知道你做了什么、谁因为你变好了 |
| 6 | **有没有浪** | 没有蓄势，一上来就把整个产品摊开，等于直接跳到发售日 |
| 7 | **最能促单的信息写了没** | 截止日期、名额、涨价只在海报上，正文没写 |
| 8 | **前后一致吗** | 正文和海报的名称、权益、价格、设备要求对不上 |
| 9 | **外部数据可靠吗** | 引用的报告名称、年份、原文意思要核对；拿不准就不用 |
| 10 | **评论区** | 有人举手（「感觉在说我」）却只回了一句玩笑，没接私聊 |

### 诊断的交付

1. 为什么没回响：按上表列出命中的几项，每项一两句，引用原文
2. **要留下的好东西**：原文里最像用户本人的那一段、最具体的痛点、最真实的故事。诊断不是全盘否定
3. 改写方向：拆成一组还是改一条；如果正在发售期，接 `launch.md` 排后面几天

## 四、用户说「写得差」时

- 先问他站在读者角度哪里不想看、哪里不想买，再改
- 常见原因：开头不抓人；只完成了任务，没有增量；离用户自己的经历太远；被他原来那条文案的结构框住了
- 用户补充的经历和观点，比任何技巧都重要：他说的话，原样保留进稿子

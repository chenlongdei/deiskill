# 浪潮式发售：给一个产品排好整个发售期

> 用户要卖一个课程或产品时读。写文案时同时读 `copy-rules.md`。9 步的详细说明在 `methodology.md` 模块⑤。

## 一、先问清这几件事

| 要知道的 | 为什么 |
| --- | --- |
| 产品是什么、多少钱、有几档价格 | 每档价格的截止点就是一个浪头 |
| 开售日、各个截止日、开课或交付日、退款期 | 决定排期 |
| 现在已经卖出多少、之前已经发过什么 | 已经开卖的，从现状接着排，不从头来 |
| 目标卖多少 | 可以先空着 |
| 有哪些真实素材：学员或客户的原话截图、案例、诊断记录、现场照片 | 决定前几天能写什么 |
| 用户的风格提示词、素材库 | 写文案前必读 |

## 二、排期：从读者的五个问题倒推

读者掏钱之前，心里在问五个问题。每天发的东西，就是轮流回答它们：

| 读者心里的问题 | 什么能回答它 |
| --- | --- |
| 1. 这跟我有关吗？ | 和他一样的人、和他一样的问题 |
| 2. 他真能解决吗？ | 已经解决掉的真实案例，有前后对比 |
| 3. 我这种人学得会、用得上吗？ | 一个明显和他一样「不懂」的人做到了 |
| 4. 到底能得到什么？ | 用「以前 → 之后」讲清每一部分，不用名词堆 |
| 5. 为什么是现在？风险呢？ | 截止时间、涨价、退款承诺 |

### 一般节奏（低价课、几晚直播这类）

| 阶段 | 时长 | 在干什么 | 卖不卖 |
| --- | --- | --- | --- |
| 预热（造势能） | 开课前 3 周 → 前 2 周，约 7 天 | 讲故事、给干货、晒过往反馈 | 不卖，最多说「在准备一件事」 |
| 发售 | 开课前 2 周 → 前 1 周，5—7 天 | 正式开卖；早鸟价制造第一个截止点 | 卖 |
| 上刺刀 | 开课前 1 周 → 开课 | 每天一个新的成交理由；涨价后第二个截止点 | 卖 |
| 延续 | 开课 → 退款期截止 | 晒现场；「还能上车、还能退」 | 卖 |
| 收尾（扫战场） | 结束后 2—3 天 | 结果、反馈、预约下一期 | 预约 |

- **两个浪头最常见**：第一浪是早鸟截止（价格），第二浪是开课（「开课了还能上车，不满意可退」，风险最低）
- **起步晚了就压缩**：前四步（定计划、盘客户、摸线索、造势能）可以压到 2 天，但预热那几条不能省
- **第一浪没起来**：把它当第一浪，起第二浪；不要延期截止日，一延期以后所有截止都没人信

### 每天发多少

| 时段 | 发什么 |
| --- | --- |
| 早上 7—9 点 | 一招方法，或前一晚留的问题的答案 |
| 中午 | 生活、现场、用户平时的观点短句，保持人设 |
| 晚上 8—10 点 | 主线：故事、反馈、成品 |
| 截止日加发 | 价格、名额、截止时间，短 |

每天 2—4 条；**带价格的每天最多 1 条**，只在截止日、涨价日和开课前后发。

## 三、交付物：发售方案的结构

存到 `05_成品/朋友圈/发售/<批次>/发售方案.md`：

1. **浪怎么排**：一张时间线，标出每个浪头和截止点
2. **9 步落到这一期**：5W2H 定计划；客户分 A（问过价、上过课）、B（常互动）、C（其余）；销售抓手；裂变（比如多人同行价）
3. **每天发什么**：日期、时段、阶段、模板、这条干什么、带不带价格
4. **前 3—5 天的文案全文**：按 `copy-rules.md` 写；后面几天先写方向，按真实进展再写
5. **私聊话术**：按阶段、按标签，每次带一个只属于对方的细节；不群发同一段话
6. **私下记录表**（见第五节）

## 四、文案怎么串起来

- **一条接一条**：前一条留的问题，后一条接住。例如：晚上抛出一个反常的发现 → 第二天早上给答案和一招方法 → 晚上一个真实的人照着做了 → 截止日讲清楚产品就是这个答案的完整版
- **产品介绍用「以前 → 之后」**：每一部分写清楚读者以前怎么做、学完或用完以后怎么做。只写「采情报、建资产」这类名词，读者看不懂和自己有什么关系
- **「别急着给我转钱」类的真诚话放在截止前最后一晚压轴**，比埋在长文末尾有力
- **反向筛选**：「这三种人别报」，说劝退，反而让对的人更想进
- **答一个真实的高频问题**，比报人数更能打消犹豫；问题和答案都要是真的，比如「要不要电脑」就照实答

## 五、私下记录表（每晚 2 分钟，不发朋友圈）

```text
| 日期 | 时间 | 哪一条 | 点赞 | 评论 | 私聊 | 报名 | 私聊里听到的原话 |
```

- 把这次发售之前、没按方法发的那条也填进去当对照组
- 私聊里听到的原话，是下一次发售最好的素材

## 六、发售结束以后

1. **一周内复盘**：哪一条带来的私聊最多、哪一天成交最多、哪句话私聊里最管用、哪几条几乎没反应
2. **结果好**：可以发一条「同一个产品，两种发法」，把对照组和新做法的数据摆在一起；课程里也当真实案例讲
3. **结果一般**：不公开，私下调整下一期
4. **写进素材库**：学员的原话和变化（注明是否已同意）、数据好的朋友圈原文、私聊里的高频问题和回答。**每一期的记录，就是下一期的发售素材**

## 七、给用户的提醒

- 发售期间不在朋友圈里公开「我在做实验」：数据不好看反而伤人设
- 评论区里第一个说「感觉在说我」的人，是在举手；当天私聊，不要只回一句玩笑
- 海报上的信息和朋友圈的说法要一致（名称、价格、赠品、设备要求）

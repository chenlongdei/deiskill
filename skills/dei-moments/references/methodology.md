# 朋友圈私域经营：七个模块

> Step 1 判断出要做的事以后，只读对应的模块。发售的完整做法在 `launch.md`，写法规则在 `copy-rules.md`。
> 标了「建议起点」的数字是给新手的起步参考，跑两周以后按复盘数据调整。

## 总览：一条闭环，七个模块

```text
① 体检 ──→ ② 日常节奏 ──→ ③ 弹药库 ──→ ④ 爆品策划 ──→ ⑤ 浪潮式发售
  ↑                                                          │
  └──────── ⑦ 复盘 ←──────── ⑥ 一鱼多吃 ←─────────────────────┘
```

| 模块 | 回答什么问题 | 产出物 | 多久做一次 |
| --- | --- | --- | --- |
| ① 体检 | 我的私域地基牢不牢？先补哪块？ | 100 分自测结果 + 最大卡点 | 每季度 |
| ② 日常节奏 | 每天发几条、几点发、发什么类型？ | 一周内容日历 | 每周排一次 |
| ③ 弹药库 | 每一条具体怎么写？ | 10 个写作公式 | 天天用 |
| ④ 爆品策划 | 一个主推产品怎么写出 100 条不重样？ | 卖点 × 角度矩阵 | 每个主推产品一次 |
| ⑤ 浪潮式发售 | 一次集中卖货怎么组织？ | 发售计划 + 时间轴（详见 `launch.md`） | 每次活动 |
| ⑥ 一鱼多吃 | 一条好内容怎么在别的平台再用？ | 短视频选题、脚本、公众号文章 | 每周挑 1—2 条 |
| ⑦ 复盘 | 哪些有效，下一轮怎么调？ | 周、月、年复盘表 | 每周 |

## 三条总原则

1. **朋友圈是一部连续剧，不是广告位。** 别人愿意看你的广告，是因为先看了你的生活和专业。所以日常节奏里，个人和专业内容要多于产品内容（见模块②）。
2. **一条朋友圈只干一件事**：建信任、立专业、促成交、引流量，四选一。想一条全干，结果一件都干不好。模块③的 10 个模板就是按这四件事分的。
3. **AI 负责写，人负责真。** 照片、截图、真实经历、客户原话，AI 编不出来，**也绝不能让它编**。客户证言、成交截图造假，一次就能把信任全毁掉。AI 的工作是把你的真素材写成你的口吻。

### 给 AI 下任务的统一格式

后面每个模块的 AI 提示词，都套这个六段结构。前三段写好一次，以后反复用：

```text
【我是谁】风格提示词（从你的语料反推出来的，见 `style-prompt.md`）
【我怎么说话】我自己写的 3 条朋友圈原文
【我卖什么】产品或服务，一句话 + 价格 + 适合谁
【这条的任务】用哪个模块、哪个模板，起什么作用（建信任 / 立专业 / 促成交 / 引流）
【素材】今天发生的事、照片里有什么、客户原话（要打码）
【禁忌】不用「家人们」，不堆表情，不灌鸡汤，不编数字和证言
```

## ① 体检：私域基础建设自测（满分 100）

**先体检再发朋友圈。** 地基有问题，比如产品同质化、没有 IP 定位、加来的人不精准，朋友圈写得再好也卖不动。

| 模块 | 分值 | 自测项（每项满分） |
| --- | --- | --- |
| 产品梳理 | 30 | 是否非标：① 和自己的公域内容相比有没有明显差异（5）② 和同行相比有没有明显差异（5）<br>是否高客单：③ 产品价格是不是高低搭配的漏斗结构（5）④ 有没有单品复购、多品交叉复购（5）<br>是否高利润：⑤ 规模变大以后，每多卖一份的成本是否稳定（5）⑥ 利润率是否超过 30%（5） |
| IP 梳理 | 30 | ⑦ 有没有输出内容的能力和兴趣（10）⑧ 生活和工作中有没有较强的个人影响力（10）⑨ 有没有明确的 IP 定位（10） |
| 流量梳理 | 20 | 新增流量：⑩ 是否稳定、持续（5）⑪ 是否精准、能转化（5）<br>私域存量：⑫ 是否加在 IP 本人的微信上（5）⑬ 好友对 IP 有没有认知（5） |
| 转化路径 | 20 | ⑭ 客户是不是主要因为信任 IP 而付费（10）⑮ 客户现在是不是主要在私域成交（10） |

**怎么看分数**：80 分以上是优秀，继续加大新增流量、加强销售力；50—80 分及格，抓重点环节优化；50 分以下不及格，要从头梳理。

**同时回答三个问题**：客户从哪里加来的，各占多少（抖音、视频号、小红书、B 站、转介绍）？当前最大卡点是流量太少、流量不精准，还是私域销售力差？现在私域里有多少人？

### 补充：分数低在哪，下一步做什么

| 低分模块 | 说明 | 先做哪个模块 |
| --- | --- | --- |
| 产品 | 卖的东西本身没区分度，或者只有一个价位 | 先回去打磨产品和价格结构；朋友圈先放一放 |
| IP | 没定位、不爱输出 | 先做 IP 定位和风格提示词，再上 ② 日常节奏，个人内容占大头 |
| 流量 | 人少或不精准 | 朋友圈解决不了人少的问题，要配合公域（短视频）引流，用 ⑥ 一鱼多吃把朋友圈内容搬到公域 |
| 转化 | 人够、信任也有，但成交不在私域 | 重点做 ④ 爆品策划和 ⑤ 浪潮式发售 |

### AI 怎么帮

```text
下面是我对「私域基础建设自测卡」15 个问题的回答（附上回答）。
请你：1. 逐项打分并说明理由，拿不准的项问我，不要替我编；
2. 算出四个模块的分数和总分；
3. 指出最该先补的一块，以及接下来两周最该做的 3 件事。
```

## ② 日常节奏：私域 IP 常规型朋友圈策划

### 内容从哪三个方向来

| 方向 | 可以写什么 | 起什么作用 |
| --- | --- | --- |
| 个人 | 家庭、生活、情感、八卦、感悟 | 让人觉得你是个活人，愿意跟你交朋友 |
| 专业 | 行业动态、行业八卦、团队动态、业务动态、客户证言、干货分享、行业观察 | 让人相信你懂行 |
| 产品营销 | 产品背景、生产流程、产品介绍、专业科普、使用场景、客户证言 | 让人想买、敢买 |

### 排一张周表

内容按类型分成「长销产品、个人/信息干货、活动」三类，工作日和周末分开排频次和时间。下面是一人公司的**建议起点**：

| | 工作日 | 周末 |
| --- | --- | --- |
| 每天条数 | 3—4 条 | 2—3 条 |
| 时间 | 早上 7—9 点、中午 12 点前后、晚上 8—10 点，选其中 2—3 个 | 上午 10 点前后、晚上 |
| 配比 | 个人 1 条 + 专业 1 条 + 产品最多 1 条，活动期另加 | 以个人和生活为主，产品可以不发 |

**周表模板**（每周日晚上排下周）：

| | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 早 | | | | | | | |
| 午 | | | | | | | |
| 晚 | | | | | | | |

每一格写「方向 + 模板 + 素材」，比如「个人 · 自拍暴露 · 周一早上的花市」。

### AI 怎么帮

```text
【我是谁】【我怎么说话】【我卖什么】（照统一格式填）
这周我手上有的素材：（列出这周会发生的事、要做的活动、已有的照片和客户反馈）
请按「工作日每天 3 条、周末每天 2 条，产品类不超过三分之一」排一张下周的朋友圈日历。
每一格写清：方向（个人/专业/产品）、用哪个模板、用哪个素材、一句话内容要点。
素材不够的格子空着，标「需要补素材」，不要编。
```

## ③ 弹药库：10 个高转化朋友圈模板

10 个模板里有两个都叫「自拍暴露」：上表那个讲**产品的使用场景**，下表那个是**此刻的自拍加心情**，作用不同。按「一条只干一件事」重新分组如下：

### 建信任：让人觉得你真实、和自己有关

| 模板 | 公式 | 必备素材 | 注意 |
| --- | --- | --- | --- |
| 连续剧自爆（看我的故事） | 想法 → 发生了（某时某地，遇到某人，发生某事，有什么冲突）→ 让我觉得 | 一件真实发生的事，有冲突 | 可以连载，结尾留个「下回分解」，让人追着看 |
| 自拍暴露·此刻 | 此刻的自拍 + 我的心情 | 一张当下的自拍 | 增加真实感；不要精修过头 |
| 获得感 | 作为（身份），因为（事情），获得了（启发、感悟） | 一个具体的经历 | 重点是「对读者也有用」，不是自我感动 |

### 立专业：让人相信你懂行

| 模板 | 公式 | 必备素材 | 注意 |
| --- | --- | --- | --- |
| 专业科普 | 一个问题（用户好奇或有误解）+ 一个答案（绝对专业、正确） | 客户常问的问题 | 说出你们行业用户不知道的信息；答案必须正确 |
| 产品背景 | 秉承（理念），经历了（有矛盾、有冲突的情节），团队伙伴做了（哪些努力），与（哪些合作伙伴）达成合作，塑造了（什么样的产品） | 产品诞生的真实经过 | 冲突是看点，没有冲突就是说明书 |
| 生产流程 | 我在（场景），看到了（生产环节），有（辛苦） | 现场照片、视频 | 一定要配现场图和视频 |

### 促成交：让人想买、敢买

| 模板 | 公式 | 必备素材 | 注意 |
| --- | --- | --- | --- |
| 产品介绍 | 针对（什么问题），解决了（哪些痛点），在（什么场景下使用），我们（凭什么能解决） | 产品图 | 配图、配图、配图 |
| 自拍暴露·使用场景 | （具体使用场景），解决了（痛点或需求），最后（获得什么结果） | 自己或客户使用时的照片 | 场景越具体越好 |
| 客户证言 | 支付截图 + 私聊截图 + 好评截图 | **真实的**截图 | 打码客户信息；绝不伪造 |

### 引流量：让人加你、不删你

| 模板 | 公式 | 必备素材 | 注意 |
| --- | --- | --- | --- |
| 超级赠品钩子 | 用户想要 + 我没成本 + 拿了不会删我 | 知识付费：PDF 资料；卖货：代金券、赠品、抽奖 | 赠品要和正价产品相关，吸引来的才是精准客户 |

### 补充：模板、语料、素材各管什么

- **模板**管结构：这条先说什么、后说什么
- **语料**管口吻：读起来像不像你（见 `style-prompt.md`）
- **素材**管真实：照片、截图、经历

三样缺一样：缺模板会写散，缺语料会有 AI 味，缺素材就成了空话。

### AI 怎么帮

```text
【我是谁】【我怎么说话】（照统一格式填）
【这条的任务】用「连续剧自爆」模板，作用是建信任。
公式：想法 → 发生了（时间地点、人、事、冲突）→ 让我觉得。
【素材】（用大白话说一遍发生了什么，越具体越好）
请写 2 版：一版 100 字内，一版 200 字左右分 3 段。结尾留一个让人想追问的点。
```

换模板时只改【这条的任务】那一段。

## ④ 爆品策划：三步写出 100 条

主推一个产品时，最常见的问题是写了五六条就没得写了。三步法解决这个问题：

1. **选一个爆款产品，简述它**：是什么、多少钱、给谁用
2. **提炼主要卖点或亮点**：建议 4—6 个，每个一句话
3. **策划 100 条朋友圈**：分 8 个角度（A—H），每个角度定条数和负责人

### 补充：8 个角度建议怎么分

8 个角度按模块③的模板来分，每个角度直接对应一个现成的写法：

| 角度 | 写什么 | 对应模板 |
| --- | --- | --- |
| A | 产品为什么诞生 | 产品背景 |
| B | 幕后：怎么做出来的 | 生产流程 |
| C | 用户遇到的问题和痛点 | 专业科普 |
| D | 行业误区，用户不知道的事 | 专业科普 |
| E | 我自己在用 | 自拍暴露·使用场景 |
| F | 客户用了以后 | 客户证言 |
| G | 为什么选我们，不选别家 | 产品介绍 |
| H | 福利、赠品、限时 | 超级赠品钩子 |

**矩阵算法**：5 个卖点 × 8 个角度 = 40 个组合，每个组合写 2—3 版，就接近 100 条。一个人不用全写完，挑最好的 30 条，放进模块②的周表里慢慢发。

### AI 怎么帮

```text
【我卖什么】（产品简述）
【卖点】1. … 2. … 3. … 4. … 5. …
请做一张 5 行（卖点）× 8 列（角度 A—H，见下）的表，每格写一个朋友圈切入点，一句话即可。
A 产品为什么诞生　B 怎么做出来的　C 用户痛点　D 行业误区　E 我自己在用　F 客户用了以后　G 为什么选我们　H 福利赠品
需要真实素材的格子（照片、证言、截图），在格子里标「需要：××」。
```

然后从矩阵里挑格子，交给模块③的提示词逐条写。

## ⑤ 浪潮式发售：集中卖货的 9 步

浪潮式发售的核心：**不是发售那天才开始卖，而是提前一层一层把势能推上去，到发售日集中引爆。** 9 步分成三段：

### 发售前：蓄势（第 1—4 步）

| 步 | 名称 | 关键动作 | 要想清楚的问题 |
| --- | --- | --- | --- |
| 1 | 定计划 | 明确活动目标；明确执行方案 | 5W2H：卖什么（what）、为什么卖（why）、在哪卖（where）、谁来卖（who）、怎么卖（how）、卖多少钱、目标多少（how much） |
| 2 | 盘客户 | 目标客户分类；线索收集方案；打造销售抓手 | 客户怎么分类？怎么收集线索？销售抓手是什么（让人先迈出一小步的东西，比如赠品、体验课、预约名单）？ |
| 3 | 摸线索 | 管理客户标签；私聊精准客户 | 标签的优先级怎么排？不同标签的人分别怎么私聊？ |
| 4 | 造势能 | 持续宣发轰炸；借势私域 KOL；制定裂变机制 | 有哪些宣发渠道，各用什么策略？KOL 从哪来、怎么激励？裂变怎么设计？ |

### 发售时：引爆（第 5—7 步）

| 步 | 名称 | 关键动作 | 核心 |
| --- | --- | --- | --- |
| 5 | 倒计时 | 发售前一天；锁定精准客户 | 对高意向客户逐个触达，蓄势待发 |
| 6 | 发售日 | 梳理发售流程；极速触达成交 | 一切围绕成交，注意力不要跑偏 |
| 7 | 上刺刀 | 销售一对一逼单；全方位触达 | 各渠道持续发力，持续给出新的成交理由 |

### 发售后：收尾（第 8—9 步）

| 步 | 名称 | 关键动作 | 核心 |
| --- | --- | --- | --- |
| 8 | 扫战场 | 做好售后承接；释放品牌势能 | 总结、宣发、求助，为下一个循环做准备 |
| 9 | 复盘 | 进入模块⑦ | — |

### 时间轴

9 步可以排成 6 个阶段，每个阶段写清时间、渠道、动作、责任人：

| 阶段 | 对应步骤 | 时间 | 渠道 | 动作 | 责任人 |
| --- | --- | --- | --- | --- | --- |
| 筹备期 | 1—2 | | | | |
| 前期传播 | 3—4 | | | | |
| 即将开始 | 5 | | | | |
| 全面宣发销售 | 6 | | | | |
| 销售冲刺关单 | 7 | | | | |
| 活动复盘存档 | 8—9 | | | | |

### 补充：一人公司的 10 天朋友圈发售（建议起点）

标准做法是按团队设计的，有责任人、KOL、多渠道。一人公司没有团队，建议压缩成 10 天，主战场就是朋友圈加私聊：

| 天 | 阶段 | 朋友圈怎么发 | 用哪些模板 | 私聊做什么 |
| --- | --- | --- | --- | --- |
| D-10 至 D-5 | 前期传播 | 只讲问题、讲故事，**不提卖** | 连续剧自爆、专业科普、获得感 | 给客户打标签（A 高意向 / B 有兴趣 / C 观望） |
| D-4 至 D-1 | 即将开始 | 透露要做一件事，放出赠品钩子，开预约名单 | 超级赠品钩子、客户证言、产品背景 | 私聊 A 类，邀请进预约名单 |
| D0 | 发售日 | 正式介绍，晒真实的成交和反馈 | 产品介绍、使用场景、客户证言 | 预约名单逐个通知 |
| D+1 至 D+3 | 冲刺关单 | 答疑、新的证言、最后期限 | 专业科普（答疑）、客户证言 | 私聊 B 类；已经问过价的逐个跟进 |
| D+4 | 扫战场 | 感谢、交付现场、预告下一次 | 生产流程（交付现场）、获得感 | 售后跟进，邀请写反馈 |

**红线**：

- 稀缺和倒计时必须是真的。说「只剩 3 个名额」，就真的只剩 3 个
- 成交截图、客户反馈只用真实的，打码后再发
- 私聊不群发同一段话，按标签写不同的开场
- 少用「最」「第一」这类绝对化用语，有违反广告法的风险

### AI 怎么帮

```text
【我是谁】【我怎么说话】【我卖什么】（照统一格式填）
我要在 X 月 X 日发售这个产品，目标卖 N 份。我是一个人运营，主要靠朋友圈和私聊。
请按「浪潮式发售」的 9 步，帮我：
1. 先用 5W2H 把计划理清，不清楚的地方问我；
2. 排一张 D-10 到 D+4 的朋友圈日历，每天 2—3 条，写明用哪个模板、一句话要点；
3. 给 A、B、C 三类客户各写一个私聊开场，语气要像我平时说话；
4. 列出我需要提前准备的真实素材（照片、截图、证言）。
```

客户分类也可以交给 AI：把你对每个客户的备注（**去掉姓名和电话**）贴进去，让它按 A、B、C 分组，并说明理由。

## ⑥ 一鱼多吃：一条好内容用四次

分四步：

1. **选素材**：选一条或几条适合延展的朋友圈主题
2. **提炼短视频选题**：标题要一句话就有冲突感
3. **写脚本**：把选题写成短视频脚本
4. **串联成公众号文章**：几条相关的朋友圈 + 视频内容，串起来，起个标题

### 补充：反过来也能吃

- **朋友圈 → 短视频 → 公众号**（常规方向）：适合朋友圈写得多、平台内容少的人
- **短视频 → 朋友圈**（反方向）：已经拍过视频的，把视频转成文字，拆成 3—5 条朋友圈。用任何音视频转文字的工具都行

挑哪条来「多吃」：用模块⑦的数据，选**互动多、带来私聊多**的那条，不要凭感觉选。

### AI 怎么帮

```text
下面是我这周反响最好的 3 条朋友圈（附原文和互动情况）。
请：1. 各提炼 1 个短视频选题，一句话标题，要有冲突感；
2. 挑最好的一个写成 60 秒口播脚本：开头 10 秒逐字写，后面只写观点提纲，我要用自己的话讲；
3. 把 3 条串成一篇公众号文章的提纲，给 3 个标题备选。
```

## ⑦ 复盘：私域数据复盘

| 周期 | 看什么 |
| --- | --- |
| 每周 | A 新增流量：本周合计、本月合计、目标完成率<br>B 业绩情况：各产品业绩、目标完成率<br>C 转化：新流量的转化率、产品总转化率、新流量的转化周期，各自是降低、增长还是稳定 |
| 每月 | 各渠道（抖音大号、抖音小号、公众号、视频号……）的转化率、总流量、总成交、总转化周期；各渠道每周的流量 |
| 每年 | 销售总额（GMV）、平均转化率、每单价值、每单成本 |

### 补充：朋友圈本身也要复盘

渠道复盘看的是渠道和业绩，没有细到「哪类朋友圈有用」。一人公司建议每周加一张小表：

| 日期 | 方向 | 模板 | 点赞 | 评论 | 带来的私聊 | 带来的成交 |
| --- | --- | --- | --- | --- | --- | --- |

跑满 4 周，就能看出自己的哪类模板最带私聊、最带成交，下个月的周表就多排这一类。**数据要真实记录，不要估。**

### AI 怎么帮

```text
下面是我过去 4 周的朋友圈记录表和业绩（附表格）。
请：1. 找出带来私聊和成交最多的 3 类内容（方向 + 模板）；
2. 找出发得多、但几乎没带来私聊的内容；
3. 按结果调整下个月的周表配比，说明理由。
数据不够下结论的地方，直接说不够，不要硬分析。
```

## 附：用性格色彩调整写法（可选）

> 下表是经验性的建议，不是测评结论；用户如果熟悉性格色彩，以他的判断为准。

同一套方法，不同性格底色的人，舒服的写法和容易踩的坑不一样：

| 底色 | 最顺手的模板 | 容易踩的坑 | 发售时适合负责 |
| --- | --- | --- | --- |
| 红 | 连续剧自爆、自拍暴露·此刻 | 想到哪发到哪，没有节奏；产品内容太少 | 造势能、发售日的热闹氛围 |
| 蓝 | 专业科普、产品背景 | 写得太长太满；不好意思谈成交 | 定计划、写长文、做复盘 |
| 黄 | 客户证言、产品介绍 | 产品内容太多，像广告号；个人内容太少 | 上刺刀、冲刺关单 |
| 绿 | 获得感、自拍暴露·使用场景 | 发得太少，怕打扰别人；逼单很难开口 | 售后承接、扫战场 |

用法：把风格提示词放进统一格式的【我是谁】，AI 就会按你的底色调整写法。周表里多排你顺手的模板，再有意识地补你回避的那一类。

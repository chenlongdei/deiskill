# 表达顺序与口吻

## 整场骨架（90 分钟 ≈ 60 页）

| 段 | 页数 | 做什么 |
|---|---|---|
| 封面 + 课前准备 + 讲师 | 3 | 课程名；wifi、软件、物料；本地背书 |
| 抛问题 | 1 | 让听众心里算一笔账（「上个月你花在稿子上多少小时」），不用举手 |
| 为什么是现在 | 1—3 | 先讲上级或官方的表态（原话 + 来源），再讲同系统已经在做的案例，最后讲离听众最近的一个 |
| 划清边界 | 1 | 别人做的是 A，今天讲的是 B |
| 三个问题 | 1 | 「首先第一个……第二个……第三个……」，与三个模块一一对应 |
| 安全底线 | 1—2 | 初稿不是定稿；涉密不上网；红黄绿分级 |
| 路线图 | 1 | 三件事，逐级递进（一个人 → 不用人盯 → 一群人） |
| 每个模块 | 10—20 | 见下 |
| 收尾 | 4—5 | 总结拍照页 → 课后自练 → 回扣现场互动 → 文化收尾 → 封底 |

## 模块内部的节奏

1. **模块封面**（主视觉，「第 N 件事」+ 一句话价值）
2. **一个熟悉的场景**（「活动办完的那个晚上」）
3. **一个概念对比**（嘴 vs 手、任务 vs 空间），每页只讲一组对比
4. **现场演示**（截图页，讲稿里标 🖥）
5. **「但是——」** 转折，然后做翻车实验
6. **方法**（指令三件套 / 规矩 / 核对关卡），引一句文化名句来承接
7. **小结页**（主视觉 + 一句话 + 三条要点，专门留给听众拍照）

模块之间要逐级往上走，价值不能重叠。每个模块回答一个开场时提出的问题。

## 讲者口吻（写演讲者备注时用）

- 开场用「那我们正式开始啊」，转场用「那我们进入第……」「好，到这里……」。
- 列举时说「首先第一个……第二个……」。
- 解释概念先说「说白了就是……」，再给出大白话。
- 等待演示时说「我们等待片刻，大概两分钟」，把等待时间拿来讲下一页。
- 自我介绍从「熟悉我的朋友知道……」开始。
- 遇到可能有争议的点，先坦白说一句（「说实话……」「再说一句实话……」）。
- 备注写成能直接念出来的句子，不写提纲；（括号）里放给讲者的动作提示。

## 场合适配（政务 / 团委类）

- 先引用官方表态，用「会议指出」，不说「某领导说」。引文后面标来源和日期。
- 案例按亲疏排序：同系统 → 同城 → 外地标杆。
- 演示材料一律虚构，并在页脚注明「虚构演示数据」。
- 红线页必须有：「涉密不上网，上网不涉密」，以及未成年人、人事信息不给 AI。

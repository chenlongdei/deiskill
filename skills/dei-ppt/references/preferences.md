# 讲者偏好（从亲手改稿里学来的，优先级最高）

> 每次讲者交回改版，跑 `keynote_diff.py`，把可复用的规律追加到这里，注明日期和来源。只记讲者确认过的规律，不记一次性改动。

## 2026-11-16 · 区级政务单位专场（白底版，Keynote 改版，模块一、二）

1. **封面写课程名，不写口号。** 标题用课程正式名称（如「AI Agent 政务办公实战」），副标题一句话说清楚交付什么（「活动信息与宣传物料的一站式生成」）。口号放进开场去讲。封底和封面同名，不再回到口号。
2. **署名用真名。** 政企场合不用网名或笔名。
3. **人物页靠背书，不靠头衔。** 写本地机构名、媒体报道、带数字的结果（「某项分析从几天缩到当天」这种前后对比）。不写听众听不懂的行业黑话（如 FDE）。素材从 dei-profile 取，优先选和听众同城、同行业的案例。
4. **开场后加一页「课前准备」。** 连 wifi、下载并登录软件、建群、领物料，每项一行。
5. **能放截图就不放金句页。** 演示环节放真指令、真界面、真成品，用红框、红箭头标出重点。「我不碰电脑」这类表演型金句，讲者嘴上说就够了，不需要单独一页。
6. **用软件界面里的真名字。** 概念名后面括注界面上的叫法，如「工作空间（分组）」。
7. **开场提出几个问题，就对应几个模块，各模块逐一回答。**
8. **文化引用必须推动论点。** 能引出一条规则、或者承担收尾的引用保留；只是修辞加码的删掉。
9. **命名朴素。** 功能名优于拟人比喻（「创建与编辑」，不写「信息报送员」）。
10. **标题里的关键短语标红。** 一个标题只标一处。
11. **场景名不挂在练习标题上。** 「课后自练」就够了，场景写在正文里。

## 2026-11-16 · 一场创业者沙龙（主题版，讲者口头反馈生成版）

12. **一页只放一个重点，注意力留给讲者。** 不要把进度条、标题、指令框、说明小字、手册章节、限时、二维码都堆在一页上。一页至多：标题 + 一个主体（指令框 / 截图 / 一组卡片）+ 一行补充。
13. **辅助信息做轻、放右下角。** 手册章节号、限时写成页码旁的一行小字；流程进度条缩小、半透明，只写出当前这一步的名字。
14. **听众已有的东西不每页重复。** 手册提前发过，就不再每页放扫码二维码。
15. **不写人人都会的操作步骤**（如「长按 → 复制 → 粘贴」），也不写和大字重复的说明（大字「3:00」下面不再写「说够 3 分钟」）。讲者现场会教的操作，页面只讲为什么（如「以前违规 → 现在有合规办法」），步骤不上屏。
16. **人物页一栏排、字号统一。** 不分三栏，不让左小右大、左黑右紫；身份和成果用同一字号同一颜色，只把成果里的数字标强调色。
17. **一页列一组工具时，拆成一类一页**，每个工具写「适合干什么 / 好在哪 / 要注意」。
18. **卡片别留大片空白、别左重右轻。** 卡片高度按内容收，一行卡片铺满版心；案例卡用居中排。
19. **技能包给链接，不给压缩包。** 放一个公开 GitHub 仓库，电脑对智能体说「帮我安装这个技能 + 链接」，手机打开仓库里的「手机版」整段复制，一个链接两端都能用。
20. **讲者说好的设计别再动**（这场：封面、整体海报风格）。
21. **以生成第 2 版为准，讲者只改字、改数字、加照片、加动画，版式不动。** 这一版的版式和取舍就是主题版的标杆，写法见 `theme-mode.md`。

## 2026-11-16 · 同一场沙龙（主题版，讲者 Keynote 改版，对照生成第 2 版）

22. **数字写保守、能直接用的那个。** 讲者把案例里的「每天产出多少条」改成了「每天能直接用的有几条」：要的是能用的量，不是产出总量。案例数字一律取能直接用、能当场核实的口径。
23. **工具的「要注意」写讲者自己踩过的坑。** 讲者补了「极易封号」「近期额度消耗过快，且降智严重」「国内生态」「能连接第三方软件」。这类判断 AI 不替讲者写死：先按通用情况写，在清单里标「按你的使用感受改」。
24. **用讲者自己的工具链。** 「更多语料」那页，讲者把通用做法换成了自己在用的工具（通义听悟、Obsidian 插件、得到大脑批量采集）。写方法页之前，先问讲者或者查个人资料，看他自己用什么工具。
25. **截图位能放真东西就放真东西。** 「我的风格提示词」截图框里，讲者直接贴了提示词原文。截图还没有的时候，把真实的文字原样放进框里，比占位框好。
26. **同一个动作，手机和电脑合成一句。** 「电脑 · WorkBuddy / 手机 · 豆包：对它说『帮我安装这个技能 + 链接』」：两端说的话一样就合并成一张卡，也不再放二维码。
27. **价值页的引子写成时代背景，不写道理。** 讲者把「一样东西变便宜了，值钱的就挪到它旁边」改成了「在人人都有 AI 味的时代」：先点出听众都有共鸣的处境，道理留给讲者口头说。
28. **提醒句前面加「注意：」。**
29. **动画节奏**：
    - 人物页一条条上浮。
    - 概览卡点一下依次出来。
    - 对比卡讲一张出一张。
    - 「变值钱」这类转折用擦除。
    - 指令框点击出现。
    - 引擎按这个节奏写好默认动画，卡片和它上面的字都打成组。
30. **人像照竖版，放大到 3.9 × 5.2 英寸**，比占位框大一圈，顶到信息栏的上沿。
31. **PPT 是手册的讲台版，不是另写一套。**（2026-11-16 讲者原话：「不是只给主题图片就行，还有我的手册呢，咱做 PPT 不是瞎编的。」）内容逐页取自手册，指令逐字照抄，章节号标在右下角；主题图只管样子。手册里没有的不写，缺了先问讲者或者先补手册。

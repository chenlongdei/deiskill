# 主题版：按一张主题图出整套 PPT

讲者给了海报、主视觉或品牌图，要「按这个风格做」时用这一套。

**主题图只管样子，内容只从手册来。** 开工要两样东西：学员手册（或讲者确认过的方案）和主题图，缺手册就不开工。每一页都能在手册里找到出处：指令逐字照抄，动手页右下角标出手册章节，手册里没有的步骤、工具、案例、数字都不写。引擎是 `scripts/deck_engine.js`，一条命令构建是 `scripts/build.py`，可以照着抄的内容文件是 `templates/theme_deck_template.js`。

标杆是 2026-11 的一场创业者沙龙（一小时实操，三轮动手）：生成第 2 版之后，讲者只改了字和数字、加了照片和动画，版式没有动。新项目照着它的质量来做，验收标准见文末。

## 1. 从主题图取风格（Step 2 之前做完）

1. **取色**：`python3 scripts/poster_theme.py palette <海报>`，会打印出 12 个主题色槽位的建议值。主强调色 `accent1` 取海报里最有代表性的中饱和色；警示红 `accent4` 固定是红色，只用在「风险、编造、违规」上。
2. **背景**：`python3 scripts/poster_theme.py backgrounds <海报> <assets 目录>`，从海报的颜色生成三张背景图：
   - `bg_cover.jpg`：封面和封底用。海报的氛围（渐变、拉丝），浓一些。
   - `bg_section.jpg`：章节页用。和封面同一套，但更淡。
   - `bg_content.jpg`：内容页用。底色接近白色，只在角落留一点海报的色晕，保证字清楚。
3. **logo**：讲者给的原图优先。只有海报的话，用 `poster_theme.py logo <图> <x0,y0,x1,y1> <输出.png>` 从海报上抠出来，去掉背景，改成墨黑色，并提醒讲者「要到透明底原图后替换」。
   - 讲者给的是深色底、白字的 logo（例如讲者个人品牌的 logo），用 `logo --invert` 改成透明底、墨黑字。
   - 每个 logo 在 `createDeck({ logos })` 里写清宽高比（`ratio` = 宽 ÷ 高）和三处的高度：`coverH`、`sectionH`、`closeH`。
4. **字体**：标题用思源黑体 Light，正文用 Regular，指令框和强调大字用 Medium。封面大标题用 ExtraLight，贴近海报上设计师用的细标题字。底部英文装饰字用一款衬线字体（如 Bodoni）。
5. **封面照着海报排**：logo 一排放在左上，年份放在右上，大标题和副标题居中，日期地点用一行小字，底部三段英文 tagline。讲者说过「封面很好，完全保留」，所以这个版式不要再改。

## 2. 版式只有 5 种

| 版式 | 用在哪 | 要点 |
| --- | --- | --- |
| COVER | 封面、封底 | 用海报背景；封底和封面同名、同一个样子 |
| SECTION | 章节页 | 标题和副标题靠左；左下角放英文 tagline；右下角一排 logo |
| CONTENT | 普通内容页 | 标题 36 号；左下角页脚写活动名，右下角页码 |
| HANDS | 学员动手页 | 顶部放进度条；标题下移，用 Medium 字重；限时、手册章节写在右下角 |
| STATEMENT | 整页一句话、引文 | 48 号细体居中；上方可以加一句小字引子 |

## 3. 一页只放一个重点（讲者最在意的一条）

讲者原话：「东西太多，没有重点。用户的注意力应该在我们身上。」

- **一页最多三层**：标题，加一个主体（指令框、一组卡片、截图三选一），再加一行补充。
- **辅助信息放进角落**：手册章节和限时只写成右下角页码旁的一行小字（`foot()`）。进度条要小、半透明，只写出当前这一步的名字（`progress()`）。
- **讲者口头会讲的，不上屏**：
  - 操作步骤讲者会现场教的，页面只讲为什么（例：「以前违规 → 现在有合规办法，我现场演示」）。
  - 人人都会的操作不写，例如「长按 → 复制 → 粘贴」。
  - 和大字重复的话不写：大字已经是「3:00」，下面就不再写「说够 3 分钟」，只标一个「倒计时」。
- **听众手里已经有的不重复**：手册提前发过，就不每页都放二维码；技能包给一个链接，不给 zip。
- **一行卡片铺满版心**：卡片高度按内容收，不留大片空白，也不要左重右轻。案例卡、数字卡居中排。
- **提醒句前面加「注意：」**，让学员一眼看出这是提醒，不是指令。

## 4. 页面模板（`D.P.*`）

| 模板 | 用途 | 默认动画 |
| --- | --- | --- |
| `cover` / `closing` | 封面、封底 | 无 |
| `section` | 章节页 | 无 |
| `person` | 人物页：照片在左，信息一栏排下来，同一字号同一颜色，只有成果里的数字标强调色 | 每组第一行点击出现，组内后面几行依次上浮 |
| `agenda` | 时间轴：今天的流程 | 无 |
| `statement` / `quote` | 整页一句话 / 引文（引文 + 出处 + 一句「所以呢」） | 无 |
| `cardRow` | 一行 N 张概览卡，如「成本就五样」 | 点一下，N 张依次上浮 |
| `compare3` | 三张对比卡：名字 + 适合 + 好在 + 要注意 | 点一下出一张，讲一张出一张 |
| `instruction` | 指令页：一个大指令框加一行提醒 | `animate: true` 时点击出现 |
| `beforeAfter` | 以前 → 现在 | 「现在」那张卡擦除出现 |
| `cases` | 案例卡（数字 + 谁 + 一句话），居中排 | 点一下出一张 |
| `checklist` | 打勾清单，如「你现在拥有了什么」 | 点一下，逐条上浮 |

自定义页用小部件拼：`T` 文字、`card` 卡片、`chip` 标签、`ph` 截图占位、`numbered` 编号步骤、`TT` 标题标一处高亮、`progress` 进度条、`foot` 右下角小字。

## 5. 分组和动画

- **每张卡片和它上面的字都要打成一个组**：`grp(slide, "卡1", () => { card(...); T(...); })`。讲者在 Keynote 里点一下整组就能加动画，不用一个个框去选。
- **`anim(slide, [...])` 直接写入入场动画**，PowerPoint 和 Keynote 都能读。节奏照着讲者自己加的来：
  - 讲一张出一张的（工具卡、案例卡）：每张卡单独一次点击，`fade`。
  - 一组一起讲的（概览卡、清单、人物页的条目）：点一次，后面接 `after` 依次出来，`rise`，每条 350—400 毫秒。
  - 转折、对比（变便宜 → 变值钱，以前 → 现在）：后半部分用 `wipe`。
  - 学员要照着发的指令框：点击出现。
- **签到轮播不加动画**，引擎会把每页设成定时自动翻页并循环播放。

## 6. 讲义结构（沙龙或课程的实操部分）

- **签到轮播**单独出一个文件（`build.py --checkin`），4 页循环：封面、连网和装软件、人物页、今天的流程。正片开头的这 4 页和轮播是同一份代码。
- 开场：章节页 → 人物页（再出现一次）→ 工具地图（一页总览，再一类一页）→ 一页「为什么」→ 三步路线图 → 先给结果，用截图加分数。
- **每一轮都是同一个循环**：指令页 → 打分 → 一页揭示（整页一句话或引文）→ 下一轮。三轮共用一条进度条，分数格放在右上角。
- 收尾：反例实验 → 前后对比 → 让学员自查 → 「你现在拥有了什么」→ 服务介绍 → 案例 → 价格 → 暗号 → 封底挂着不撤。
- **备用页**一律隐藏，用 B1、B2…… 编号：断网、软件认不清、装不上、没人愿意念的时候用。每页讲稿第一句写「（什么情况跳到这页）」。

## 7. 验收（交付前逐条过）

0. 拿手册对一遍：每页都有出处，指令和手册原文一字不差，章节号标得对。
1. `build.py` 的自查全部通过：每页有讲稿，没有溢出风险，动画目标都找得到。
2. 逐张看 `preview/contact_*.png`：
   - 没有一页超过三层。
   - 动手页的辅助信息都在右下角。
   - 卡片没有大片空白，也没有左重右轻。
   - 中文字体正常显示：要是中文成了空白或者变成衬线字体，说明预览缺字体，先跑 `build.py --doctor`。
3. 用 Keynote 打开一遍（macOS）：动画都在，每张卡片都是一个组。
4. 课前准备清单写全：要实测的功能、要补的截图、要核对的引文和数字、现场提醒，加上「不加动画的那些页，讲者可以自己再加」。
5. 讲者改过的 `.key` 就是正本。只把他改的字、数字和照片同步回内容文件，不用生成版覆盖正本。备用 PDF 从正本导出。

# dei-profile · 个人介绍与案例库

**出门说得清自己是谁、凭什么信你、怎么开始合作；每次讲课、见人、发资料，都从自己的案例库里挑出最对路的那几个，不用每次从头想。**

它是 [deiskill](https://github.com/chenlongdei/deiskill) 的一部分，也可以单独装、单独用。不用任何账号；出 PDF 时需要 Chrome（或 Edge）和一个 Python 包。

## 最快拿到第一个结果

装好后对你的 Agent 说：

> 我出门跟人介绍自己总说不清楚。这是我的一些素材（录音转写、以前的介绍、做过的项目），帮我梳理一下：到底该呈现什么？<粘贴或给文件路径>

它会先挑出素材里站不住的地方（别人做的写成了自己做的、没有来源的数字、太冲的词），再把站得住的经历分成「做出来的、教出来的、被认可的」三层，最后给你一句话定位，并问你主要讲给谁听。

## 安装

**和装其他 Skill 一样**（需要 Node.js）：

```bash
npx -y skills add chenlongdei/deiskill --skill dei-profile
```

**或者用一键安装**，它会顺便检查环境，重装时备份旧版本、保留你的配置：

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.sh | bash -s -- dei-profile
```

Windows PowerShell（需要先装好 git 和 Python 3.9+）：

```powershell
$env:DEISKILL_ONLY="dei-profile"; irm https://raw.githubusercontent.com/chenlongdei/deiskill/main/scripts/bootstrap.ps1 | iex
```

不想敲命令：把这个页面的网址发给你的 Agent，说「帮我安装 `dei-profile`，按 README 操作」。

它会自动识别 Claude Code、Codex、WorkBuddy 等 Agent 的 skills 目录；装好后重启 Agent。

## 它能做什么

| 你说 | 你会拿到 |
| --- | --- |
| 「帮我梳理个人介绍」 | 去伪存真后的三层证据、一句话定位；按读者分版本的介绍文档（老板和个人一版，政企和社区一版） |
| 「这是个新案例，帮我入库」 | 一张案例卡片：谁做的、事实数字和估算分开、一句话结果标题；并更新受影响的介绍 |
| 「明天给一群餐饮老板讲课，配几个案例」「按这份课程手册配案例」 | 从案例库里挑出的 1—3 个案例，每个附上为什么选它、放在哪一节讲 |
| 「见老板怎么介绍自己」「朋友介绍我怎么说」「陌拜怎么开口」 | 学员、老板、朋友引荐、陌生拜访四种场合，1 / 3 / 10 分钟的话术，用你自己的说话习惯写 |
| 「讲课用的 PPT 介绍页」 | 一页人物介绍（按场合换结果）和案例页文案 |
| 「出一版给政企看的 PDF」 | 排好版的 PDF：封面、留好的插图位，内部附录不会出现在 PDF 里；可以同步到你常用的飞书、Notion 或钉钉 |

## 用的是什么方法

来自一次真实的个人定位梳理，前后改了几轮：

- **去粗取精、去伪存真**：先挑出站不住的说法，再把真本事分成三层证据。做出来的，证明你能交付；教出来的，证明方法能复制；被认可的，证明有人背书。
- **先结果后过程**：标题写「老板每天少算 2 小时账」，不写「案例一」；不报工具名。
- **算一笔账**：没有财务反馈也能量化。把「原来 → 现在」换算成一年的时间、人力和钱，推算的数字写清依据。
- **正确的非共识**：介绍里放几句和对方平时听到的不一样、但你的案例能证明的话；读者走过的弯路，能解决就给方法，解决不了就说明问题不在他。
- **按读者分版本**：老板关心省多少钱，个人关心能不能学会，机关和社区关心安全合规、有没有亮点。
- **客户视角检查**：用三类读者各读一遍，看分流、手机阅读、行动提示、顾虑回应、第三方声音有没有到位。
- **不编**：数字、客户原话、截图只用你给的；缺的地方留空让你补。

## 准备什么、花多少钱

- 不用账号，不花钱。
- 出 PDF：Python 3.9+、`pip install markdown`，再装 Chrome、Chromium 或 Edge 里的任意一个。
- 同步到文档平台：需要对应平台的命令行并登录（飞书 `lark-cli`、Notion `ntn`、钉钉 `dws`）。

## 结果存在哪里

第一次用时，它会问你的介绍库放在哪里。你已经有自己的文件夹，就直接用它；没有的话，默认放在 dei 工作区的 `05_成品/个人介绍/`。介绍文档、案例卡片、PDF 都只存在你自己的电脑上，不会写进 Skill 目录。

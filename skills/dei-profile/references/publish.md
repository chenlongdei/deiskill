# 出 PDF、同步文档平台

## 一、PDF

```bash
python3 scripts/profile_lib.py pdf <介绍.md> --label "个人介绍 · 企业与个人版" --short "个人介绍"
```

- 默认输出到介绍库的 `02_PDF/<显示名>_<文件名>.pdf`；`--out` 可指定。
- 品牌名、英文副标、城市读介绍库的 `profile.json`。
- 版式：白底、墨黑字、荧光绿只做色块和下划线；文字 logo 旁留「正式 logo 替换位」。
- 处理规则：
  - 「# 附录」之后不进 PDF；
  - 文首到第一条 `---` 做成封面：标题在逗号处断行，括号里的版本名单独成一行小字；有数字列表就做成数字卡片，没有就把「一眼看懂」挪到封面；
  - `> 📷`、`> 💬` 变成占位框，`> 👉` 变成绿色行动卡片，`> 🙋` 变成白底卡片；
  - 行内 `` `[待补]` `` 显示成绿色高亮；
  - 一级标题另起一页；
  - 含「个人培训」的代码块画成闭环流程图。
- 依赖：`pip install markdown`；Google Chrome、Chromium 或 Microsoft Edge 任一（脚本自动找，找不到时用环境变量 `PROFILE_CHROME` 指定）。
- **生成后要看一眼**：把前两页和中间一页渲染成图片检查。常见问题有三个：标题最后一个字掉到下一行；封面下半页空白；课程名和说明挤在一行。

## 二、同步到文档平台

1. `python3 scripts/dei_workspace.py publish` 查看用户设定的平台和命令行是否装好、是否登录。还没设定就问一次，用 `publish set <平台>` 记下。
2. 只同步对外内容：去掉「# 附录」之后的部分，去掉文首 H1，把标题放进 frontmatter 的 `title`。
3. 第一次同步：先建一个总页（一段分流说明：谁看哪份），再在它下面建各版本子页面。以后更新用编辑页面，不重复新建。
4. 页面 ID 和链接记进介绍库的 `发布记录.json`（只记链接和 ID，不记令牌），并写进库里的 `CLAUDE.md` 或 README。
5. 同步完读回页面，检查表格和内容是否完整。
6. 默认不开公开分享；提醒用户发出去前在平台里打开分享。

命令参数以平台命令行自带的 `--help` 为准，不凭记忆写。

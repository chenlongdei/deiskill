# 按主题、对象、场合定制

## 一、先弄清三件事

1. **讲给谁**：老板 / 个人学员 / 政企 / 社区居民 / 混合。
2. **什么场合**：讲课开场、正式拜访、饭局、沙龙、朋友引荐、陌生拜访、加微信后第一条消息。
3. **讲多久**：1 分钟（约 250 字）、3 分钟（约 700 字）、10 分钟（提纲，不写逐字稿）。

用户给的是一份课程手册或课程方案时：先读目录和每节的核心任务，提取「这门课在解决什么问题、学员是谁」，再当成「主题 + 读者」去筛案例。

## 二、筛案例

1. 用 `profile_lib.py cases --query "<主题关键词>" --audience <读者> --top 8` 初筛。
2. 读进前几张卡片，按下面的顺序挑 1—3 个：
   - **和主题直接相关**（课讲表格自动化，就选算薪、汇总看板那类）；
   - **读者能代入**（台下是上班族，就选学员里的上班族，而不是老板）；
   - **有数字**；
   - **可点名**的优先；`public: 不对外` 的不用。
3. 每个入选案例写一句「为什么选它」，再给一个备选。
4. 讲课时，案例最好**分布在不同章节**：开场用一个最炸的结果抓注意力，讲到具体方法时再用和这一节对应的案例。

交付格式：

```markdown
## 推荐案例
1. 【开场用】<一句话标题>：选它是因为……（卡片：05_案例库/xxx.md）
2. 【第 N 节用】……
备选：……
```

## 三、自我介绍话术

### 第一印象四条

1. 第一句说跟他有关的结果，不说头衔；头衔放后面当证据。
2. 只讲一个故事、一个数字。
3. 留一句让人记住的话（招牌句），一个月不换。
4. 最后抛一个问题，让对方开口说他自己。

不要按时间线讲经历，不要报工具名，不要说「赋能」「接手和优化」这类空词。

### 万能结构

```
我是谁（一句话）→ 一个结果故事（带数字）→ 一句招牌观点 → 跟你有什么关系 → 抛一个问题
```

### 四类对象

| 对象 | 目标 | 主力故事 | 收尾的问题 |
| --- | --- | --- | --- |
| 学员 | 「他做成过，能带我做成，不忽悠」 | 学员从零到有收入的结果 | 「你最想交给 AI 做的一件事是什么？」 |
| 老板 | 「他懂生意，不是来卖课的」 | 亲手交付里省时间、省人的那个 | 「您这边现在最费人的是哪一块？」 |
| 朋友引荐 | 朋友好开口，自己接得住 | 给朋友一段 20 秒口头版 + 一段微信转发版；自己接话时先谦虚一句，马上转到对方 | 「您是做哪块的？」 |
| 陌生拜访 | 不像推销 | 和对方行业最接近的那个 | 先请教，不介绍；用「免费给您一个判断」留微信 |

### 10 分钟版：先听后讲

长版、开场、讲师介绍里的「我是谁」，从库里的 `01_个人介绍/人物档案.md` 挑故事和观点（按它的「可讲的故事」表对场合），不要按时间线把经历全讲一遍。


- 老板、陌生拜访：前 3 分钟只问问题（谁在手工汇总表格？客户从哪来？哪个环节最怕漏钱？），再按回答对号入座讲一个案例；陌拜面谈加一个**现场小演示**（当场用 AI 帮他做一件小事）。
- 学员：互动开场（「买过 AI 课的举手，用起来的呢？」）→ 我是谁和背书 → 三个判断各配一个小故事 → 按台下人群挑 2—3 个学员结果 → 学习规矩 → 收尾。

### 常见追问

提前准备：跟别人有什么区别、有什么案例（先反问对方做哪块，再挑一个，不报菜名）、多少钱、公司小用得上吗、AI 会不会替代员工、AI 不就是聊天工具吗。

### 写法

- 读库里已有的 `自我介绍话术.md` 和用户的录音、对话原话，用他的口头禅（例如「对吧」「其实」「你比如说」「说白了」），短句。
- 1 分钟和 3 分钟写逐字稿，3 分钟版标出每段的时长；10 分钟写分段提纲表（时间 / 环节 / 关键句）。
- 给出后提醒用户：念一遍，哪句不像自己说的就告诉你。

## 四、PPT 页

### 人物页（一页）

左边人像，右边：名字 + 一句身份 → **身份** 4 行（背书）→ **做成过** 4 行（带数字）→ 底部一句话。

做一个通用版，每次只换「做成过」那 4 行：老板场放企业结果，政企场放内训单位和媒体报道，社区和夜校场放学员结果。

### 案例页（每个案例一页）

```
标题：一句话结果
副标题：客户类型
左：原来（1—2 句）／我们做了（3 点以内）    右：截图
底：2—3 个放大的数字
```

每页 80 字以内，细节靠嘴讲；每页一定要有一张真实截图。

## 五、定制版介绍

按主题或对象出一份专门的介绍时：复制主介绍的骨架，换首屏数字、换案例、换课程菜单的顺序，其余不动。存为 `01_个人介绍/定制/YYYY-MM-DD_<主题>.md`，需要 PDF 时按 `publish.md` 生成。

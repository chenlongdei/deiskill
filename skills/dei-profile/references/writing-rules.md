# 写作规则：介绍文档怎么写

## 一、按读者分版本

| 读者 | 关心什么 | 语气 | 主力证据 | 成交入口 |
| --- | --- | --- | --- | --- |
| 私企老板 | 省多少钱、多赚多少、少招几个人 | 算账 | 亲手交付的企业案例 | 免费一句话判断 → 诊断（签约可抵扣） |
| 个人 / 学员 | 能不能学会、能不能变现、会不会被坑 | 共情 + 案例 | 学员结果（带数字） | 低价社群 / 陪跑，先帮他判断适合哪个 |
| 机关、国企、社区、夜校 | 安全合规、报名火不火、有没有亮点、能不能写进总结 | 稳重、实用 | 内训单位、媒体报道、课堂人数 | 免费需求调研、活动总结素材 |

很多人想跟这个人学，其实是想学会「帮老板解决问题」。面向个人的版本可以点明：「给老板」那部分的每个案例，都是你学会以后能接的活。

## 二、主介绍的骨架（企业与个人版）

1. **首屏**：一句话定位 → 3—4 个结果数字（列表，不用横表）→ 一行背书 → 「我是谁」一句 → 一个免费入口。
2. **先看你是哪一类**：按身份分流，告诉他直接看哪一段。
3. **三句可能和你听到的不一样的话**：正确的非共识。
4. **给老板**：痛点清单（「你的公司里有没有这几种活」）→ 案例（结果标题 + 原来 + 做了 + 算一笔账）→ 合作流程和报价 → 课程菜单 → 老板常问 → 行动提示。
5. **给个人**：「你是不是也这样」（弯路 + 为什么不是你的问题 + 怎么做）→ 学员结果（按人群分组）→ 方案对比 → 个人常问 → 行动提示。
6. **为什么是我**：做事原则、背书、正在搭的事（还没做到的写「正在」）。
7. **见面礼**：加微信能拿到什么，2—3 个任选。
8. **# 附录（内部用，对外删除）**：分享标题备选、发送话术、估算口径、待确认清单。

政企与社区版：首屏 + 一眼看懂（背书清单）→ 为什么现在适合办 → 不同单位解决不同问题 → 课程菜单（按人群）→ 合作形式与参考价格（单位价 / 公益价两列）→ 分工 → 一次合作怎么走 → 原则 → 联系方式 → 附录（回复话术、定价逻辑、资料来源、待确认）。

## 三、正确的非共识

- 要和读者平时听到的不一样，但能用这个人自己的案例证明。例：「大部分 AI 工具你不用学」「AI 一键生成的东西，放到市场上等于零分」「企业上 AI，第一步是把流程说清楚」「好系统的标准是我走了它还在转」。
- 优先用这个人自己说过的话，从录音和对话里找，不另起炉灶。
- 对读者走过的弯路，三段式写：**你做过的事 → 其实很正常，因为…… → 我们怎么做**。能解决的给方法；解决不了的，至少让他知道问题不在他。

## 四、案例怎么写

- 标题写结果；正文三块：**原来**（1—2 句，有数字写数字）、**我们做了**（3 点以内，大白话）、**算一笔账**（表格，换算成一年）。
- 常用换算：每天省 N 小时 × 365；一个岗位年成本 ≈ 月薪 × 12 × 1.3；全职一人一年约 2000 工作小时。
- 涉及敏感领域（政企、竞争情报）时：只说基于公开信息，不写针对具体个人的分析；写一句原则「所有信息只来自公开渠道」。

## 五、课程命名（企业内训、政企课程）

结构：**一个让人觉得有分量的大词 + 冒号 + 具体做什么**；每门课下面写「课后产出」。

- 有分量的词：AI 驱动降本增效、AI 赋能高效办公、企业知识资产化、经营数据自动化、数字员工上岗、智能体工作流实战、AI 赋能营销增长、AIGC 品牌视觉实战、AI 落地共创工作坊。
- 按买课的人分层：决策层、全员、营销团队、定制工作坊；政企再加领导干部专题、AI 安全合规、基层工作者专场。
- 社区和夜校用更亲民的「AI + X」：《AI + 自媒体：从零做一个小红书账号》。
- 不要可爱化的名字（《表格自己会算账》），企业看不出价值。

## 六、手机阅读与版式约定

- 首屏和分流不用多列表格，手机上要横滑。表格只用在「算一笔账」「价格」这类两三列的地方。
- 插图位写成 `> 📷 【配图】说明`；学员原话位写成 `> 💬 【学员原话】说明`；行动提示用 `> 👉`；「我是谁」用 `> 🙋`。PDF 脚本会把它们排成对应的框。
- 待补信息写成 `` `[待补：××]` ``。
- 文首到第一条 `---` 之间是首屏，PDF 会把它做成封面。

## 七、客户视角检查清单（交付前过一遍）

用三类人各读一遍：用手机打开链接的老板、想做副业的上班族、来采购培训的负责人。

- [ ] 第一屏能看出「跟我有什么关系」和「凭什么信你」吗？
- [ ] 每类读者 10 秒内能找到自己该看的那段吗？
- [ ] 能看出这个人是谁吗？（名字、城市、做了几年、几个人）
- [ ] 有第三方的声音吗？（学员原话、截图、媒体报道；没有就留位置并提醒用户补）
- [ ] 读到一半想联系，附近有行动提示吗？
- [ ] 读者的顾虑有回应吗？（公司小、员工不懂技术、做完没人维护、零基础、多少钱）
- [ ] 第一次出现的术语有一句话解释吗？
- [ ] 有没有把还没做到的写成已经做到？
- [ ] 每个数字都答得上「这个数哪来的」吗？
- [ ] 前后数字一致吗？（首屏、案例、附录）

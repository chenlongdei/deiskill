# dei-shop-video 门店引流短视频

## 使命

给一家门店的素材和文案，当天出一条能投的引流短视频：前 5 秒抓人、中文配音自然、每个动作都有音效、结尾把人引到团购。工程用 `project.json` 描述，改文案、换门店、换配音都只改这一份。

## 铁律

1. **配音只用中文母语音色 + eleven_v4（或 v3）模型**。非母语音色和 `eleven_multilingual_v2` 有外国腔和卡顿，用户明确否决过。先给用户试音，让用户挑。
2. **音效是核心**：每个画面动作都配上听得出是什么的音效；名字说不清是什么声音的文件不用。
3. **开头 5 秒最重要**：第 0 帧画面就在动（门头 + 定位钉 + 地域字幕），之后每秒一个新动作；价格、服务大字等口播说到时再弹出，不提前摆出来。
4. **不重复字幕**：有大花字的句子，底部不再出同样的字幕。
5. **必须有 BGM**，人声出来时压低但不能压没；成片约 -11 LUFS，不要偏小。
6. **不绕过人机验证**：Pixabay 这类有 Cloudflare 验证的网站，给链接请用户自己点下载。
7. **别人的车牌、路人的脸要打码**：用到的镜头里看得清的都打马赛克。
8. **不改客户信息**：口播、价格、店名以用户给的为准；团购卡和口播对不上时列出来交给用户确认。
9. **文案照用户给的写**：用户给了脚本就逐字用（包括大字幕写什么）；需要改写时先给用户看。

## 流程

命令都相对本 Skill 目录；Windows 上 `python3` 通常换成 `python`。

### Step 0 准备

- `python3 scripts/doctor.py`，缺什么按 `references/setup.md` 给出安装命令，用户同意后再装。没有 ElevenLabs key 时停下说明。
- 问清两件事（一次问完）：素材文件夹在哪；工程和成片放哪。这件事已经有项目文件夹的，默认放在它下面（工程 `剪辑工程/`，成片 `成片/`，或用户项目里已有的交付文件夹）；没有的，放 `python3 scripts/dei_workspace.py where` 里 `output` 下的 `门店短视频/YYYY-MM-DD_HHMM_店名/`。目录不存在先说完整路径，确认后再建。
- 读 `references/method.md`。用户给了对标视频的，先抽帧看它的结构、花字和节奏，和 method.md 不一样的地方以对标为准。

### Step 1 建工程、看素材

`python3 scripts/new.py <工程> --footage <素材文件夹> [--card <团购卡截图>] --title <名字>`

它会复制素材（统一命名 clip01…）、出 `素材缩略图/`、写一份 `project.json` 草稿。逐张看缩略图，记下每段是什么（门头、进门、前台、座椅、细节、窗边…）和好用的秒数，以及哪里拍到了别人的车牌、路人的脸。

### Step 2 文案和 project.json

- 用户给了文案：拆成句写进 `lines`。没给：按 method.md 第 1 节写一版，给用户确认。
- 按 `references/project-json.md` 改 `captions`、`shots`、`overlays`、`sfx`：镜头和图层都按「哪个字被说出」定位，大字等口播说到时再出；开头的钩子按 method.md 第 2 节排。
- 用到的镜头里有看得清的车牌、路人脸：抽帧定位后写进 `masks`，运行 `python3 scripts/mask.py <工程>`（method.md 第 8 节）。

### Step 3 配音

1. 音色：`config.json` 已有用户认可的音色就直接用；没有就 `python3 scripts/tts.py voices --gender male`（或 female）挑 3–5 个中文母语音色，`python3 scripts/tts.py sample <工程> --voices id1,id2,...` 出试音，请用户听了选。
2. `python3 scripts/tts.py make <工程>`：生成全部句子，并自动用语音识别核对；一致度低于 90% 的句子改写法后 `--only` 重做。

### Step 4 音效和 BGM

- `python3 scripts/sfx.py <工程>`：生成 project.json 里用到、还没有的音效。用户有本地音效库的，同名文件放进 `sfx_dir` 即可替换。
- BGM 按 `references/bgm.md`：给用户 3–5 个没有内容ID的链接，用户下载好后 `python3 scripts/bgm.py <工程> --latest --source "曲名 / 作者 / 平台 / 许可"`。用户暂时不下载时，用 Openverse 上 CC0 / CC BY 的曲子先出一版，并说明。

### Step 5 看画面、出片

1. `python3 scripts/finalize.py <工程> --snap-only`：生成、检查、出关键帧拼图。逐张看：首帧钩子、字是否出画或压住招牌、团购卡和箭头位置。有问题改 project.json 再看。
2. `python3 scripts/finalize.py <工程> --out <成片路径/名字_v1.mp4> --verify`：渲染、响度标准化、整条口播核对，完成后打开成片。
3. 用 `python3 scripts/dei_workspace.py log dei-shop-video "<店名>引流视频" ok <成片路径>` 记一笔。

### 改版

用户看片后的意见，按「改哪个字段」处理：配音 → `voice` 后 `tts.py make`；音效 → `sfx`；BGM 大小 → `bgm.volume` / `bgm.duck`；整体声音小 → `--lufs`；画面 → `overlays` / `shots`；调色 → `grade`。每次出新文件名（v2、v3…），旧版不删。用户反馈里有新的通用规则，补进 method.md 的对应节。

## 缺少信息时

- 没有团购卡截图：CTA 段只放箭头和大字，告诉用户补截图后重出。
- 素材太少（少于 4 段或总长不到 20 秒）：同一段素材取不同秒数、不同推拉方向，照样出片，并说明哪些画面重复了。
- 用户没给参考调色：用模板默认的提亮、提饱和。

## 边界与停止条件

- ElevenLabs 401 / 额度不足 / 限流：停下说明哪一步、已完成哪些；重跑同一条命令只补缺的（`--only`）。
- HyperFrames 检查报错：先改，不带错误渲染。渲染失败两次就停下，把错误给用户。
- 网站下载遇到人机验证、登录墙：停下，给链接请用户自己下载。

## 禁止事项

- 不用非中文母语音色、不用 `eleven_multilingual_v2` 配中文。
- 不绕过网站的人机验证、不伪造请求头下载资源。
- 不把 ElevenLabs key 写进工程、日志或回复。
- 不改原始素材文件（打码生成 `_masked` 副本）；不删旧版成片。

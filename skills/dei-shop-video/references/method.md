# 门店引流短视频的剪法

来源：一家健康馆 9.9 元新店引流视频，照一条抖音本地生活爆款复刻，改了五版。下面每条都是用户看片后的真实反馈。

## 1. 结构：5 句口播，5 个段落

| 段落 | 口播在说什么 | 画面 | 图层（project.json 的 overlays） |
| --- | --- | --- | --- |
| ① 地域钩子 0–2 秒 | 「XX 的朋友们注意了！」 | 门头 | 定位钉、地域字幕；说到「注意了」时速度线 +「注意了！」砸字 + 画面震动 |
| ② 低价钩子 2–9 秒 | 新店开业，9.9 元体验一次 XX | 闪白进门 → 前台 → 座椅 | 「新店开业」彩带、说到「9.9 元」低价爆炸贴（光芒 + 金币）、说到服务名时大标题「9.9元 / XX体验一次！」 |
| ③ 环境背书 9–13 秒 | 我们 XX 店，环境舒适、服务专业 | 念店名时给 logo 墙，之后给最好看的环境 | 卖点大字逐个弹出 |
| ④ 价格锚定 + 限量 13–20 秒 | 平时 89 元，准备了 50 份名额 | 窗边、大厅 | 原价划线、「限量 50 份」冲屏 |
| ⑤ 引导下单 20–26 秒 | 点击左下角，9.9 元直接团 | 休息区 → 门头收尾 | 团购卡弹出、左下角跳动箭头、「快来体验吧」 |

文案句数不同就增减段落；每个镜头和图层都按「哪个字被说出」定位，换文案不用重算时间。

## 2. 开头 5 秒（用户最看重）

- **第 0 帧就要有画面在动**：门头 + 定位钉落下 + 地域字幕，不能是空镜或黑屏。
- **大字跟着口播出**：价格、服务这类大标题等配音说到那几个字时再弹出，不在第 0 帧就把答案摆出来（用户看片后改的：「不要直接就出来，配合后面的口播再出来」）。脚本写了「开头大字幕」，指的是这段口播的大字，时间仍跟口播走。
- 每一秒都有一个新动作：定位钉落下 → 钩子词时速度线和砸字 → 闪白转场 → 彩带滑入 → 蓄力后低价爆出、金币飞散 → 服务大标题。
- 动作和音效一一对应（见第 4 节），不留没声音的动作。
- 文字别压住门头招牌和店名；大字放在玻璃门、墙面这类空的地方。

## 3. 字幕

- 两层：底部白字黑描边（关键词标黄），中间大花字。
- **同一句话已经有大花字，底部就不再出字幕**：captions 里这一段前面加 `#`。用户明确说过两层重复不行。
- 花字一行不超过 8 个字，宽了就缩字号，别出画。
- **字体照对标**：抖音本地生活这类视频的字幕和花字多是粗宋体（白字黑描边），价格数字是粗圆黑体。默认字幕和花字用思源宋体 Heavy，数字、定位钉、标签用抖音美好体；第一版用的普惠体 + 优设好身体被用户评价为「特效字体不是特别合适」。

## 4. 音效（用户说「核心在于音效」）

- 每个画面动作配一个音效，名字说不清是什么声音的文件不用。第一版把汽水机音效当收银声，用户听成枪声，就是这个原因。
- 首选 `sfx.py` 按 `templates/sfx_prompts.json` 生成（ElevenLabs 音效生成，提示词写清是什么声音、结尾加 no music）；用户有本地音效库时可以放同名文件替换。
- 对应关系：大标题砸下 impact、定位钉 pin_drop、钩子词 whoosh + text_slam、转场 flash + whoosh、彩带 ribbon、低价 riser → kaching + coins + sparkle、标签和卖点 pop、划线 strike、限量 impact、团购卡 ding、箭头 tap、收尾 sparkle。

## 5. 配音

- 必须是**中文母语**音色，配 `eleven_v4`（或 `eleven_v3`）模型。`eleven_multilingual_v2` 和非母语音色说中文有外国腔、卡顿，用户评价是「廉价感，不行」。
- 先用 `tts.py sample` 给用户 3–5 个试音，让用户挑；生成后 `tts.py make` 自动用语音识别核对，一致度低于 90% 的句子要改写法重生成。
- 成片里 1.1 倍速（`voice.rate`），像抖音探店的语速。

## 6. BGM

- 必须有；轻快、带鼓点的流行或放克，人声出来时压到满音量的 0.55 倍左右（`bgm.duck`），不要压没。
- 镜头切点吸附到节拍（`snap: true`），BGM 起点由 `bgm.py` 对到强拍。
- 来源和版权见 `bgm.md`。

## 7. 调色与响度

- 用户给参考截图时，整片统一套一个调色（`grade.adjust`：提亮、提饱和、白平衡往参考靠）。门店实拍通常偏暗偏黄，默认值见模板。
- 成片响度约 -11 LUFS（`finalize.py` 自动压缩 + 标准化）。-14.7 LUFS 被用户评价为「声音好小」。

## 8. 隐私：别人的车牌和脸

- 素材里拍到路边车辆的车牌、路人的脸，能看清的都要打马赛克（`masks` + `mask.py`）。用户看片时指出过窗外红车的车牌。
- 逐个镜头看用到的那几秒：每 0.25 秒抽一帧，记下车牌中心位置写进 keys；镜头在晃的，框留够余量。远处看不清的不用打。

## 9. 交付前自查

- 用 `finalize.py --snap-only` 看关键帧拼图：首帧有没有钩子、字有没有出画、有没有压住招牌、团购卡和箭头位置对不对、车牌和路人脸有没有漏。
- 成片加 `--verify`，把整条口播再核对一遍。
- 团购卡上的价格、店名要和口播一致；对不上的列出来请用户找客户确认，不自己改。

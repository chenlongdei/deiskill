# scenes.py 怎么写

`scenes.py` 只写这条视频的图解和贴纸，`build.py` 负责其余一切（人像、跳切推近、标题、进度条、字幕、音效清单）。`scenes_example.py` 是一条真实口播的定稿，**只用来查函数怎么写，不照抄它的结构**。

## 先定画面方案（写代码之前）

用户看完一条按示例套出来的片子说：「整体的剪辑特效和原本基本完全一样，就是一个模子刻出来的……对比呀、先出这个先出那个，连位置、呈现顺序都几乎一样。」所以每条先写 `画面方案.md`：

| 成片时间 | 口播在讲什么 | 类型 | 版式 | 图解写法 | 为什么这样画 |
|---|---|---|---|---|---|

**类型 → 可选的画法**（同一类型换着用，别每次都选第一个）：

| 类型 | 画法 |
|---|---|
| 框架 / N 个要素 | 逐格点亮的宫格；转盘；拼图一块块拼上；N 个节点连成环；手指逐个数 |
| 清单 / 步骤 | 步骤行 + 计数；时间轴；楼梯一级级上；打勾清单 |
| 对比 | 左右卡 + VS；天平倾斜；同一个东西前后两张（划掉 → 新的）；温度计 / 进度条两根 |
| 范围、人群、聚焦 | 圆圈越缩越小 / 靶心；漏斗；放大镜从人群里挑出一个 |
| 因果 / 推理 | 箭头链；多米诺；A → ？→ B，问号翻成答案 |
| 反例、误区 | 大字砸屏划掉；「✗」盖章；直觉 vs 真相两张 |
| 数字 | 大数字计数；柱条长出来；和熟悉的东西类比（「= 3 杯咖啡」） |
| 故事 / 经历 | 空镜；人像 + 时间地点小标签；不加图解 |
| 观点、金句 | 纯人像留白（只有字幕）；关键词大字砸屏 1 秒 |

**版式**（一条里至少 3 种，同一种别连着用超过 2 次）：

| 版式 | 函数 | 适合 |
|---|---|---|
| 整屏图解 | `scene()` … `end_scene()` | 讲结构、要停留 5 秒以上 |
| 人像 + 横条 | `band()` | 短的结构点（3 个节点、一个对比），不想切走人脸 |
| 侧边贴纸 | `sticker()` | 一个词、一个图标、一个数字 |
| 大字砸屏 | `punch()` | 反常识、转折、结论，≤1.5 秒，一条 1–2 次 |
| 空镜 | `broll()` | 故事、升华 |
| 纯人像 | 什么都不放 | 观点、情绪；给眼睛休息 |

**别和上一条撞**：开头 3 秒的钩子（计数 / 反问 / 结果先行 / 砸字 / 动作）、第一个图解的版式、各段出场顺序和位置，都要和最近一条不一样。写完跑 `python3 scripts/variety.py <工程>` 查。

**每条自动换的样式**（同一工程反复 build 不变，换一条就不同，和同文件夹最近两条错开；plan.json 可以写死）：

| plan.json | 选项 |
| --- | --- |
| `title_style`（常驻标题） | `box` 深底描边 / `tape` 荧光胶带斜贴 / `marker` 白字 + 荧光笔划线 / `kicker` 上小下大两行（标题写成「小字\|大字」）/ `bar` 左侧竖条 |
| `scene_head`（整屏图解的章节 + 大标题） | `left` 左上 / `center` 居中 / `bignum` 大号章节数字垫底 |

**字幕区不放东西**：图解内容放 560–1060；元素中心低于字幕顶部 60 像素以内，`build.py` 会报「⚠ 压字幕」。

**换风格**（同一套函数能出不同气质，别每条都是墨黑 + 荧光绿）：`plan.json` 的 `colors` 换整套颜色，`caption_style: "clean"` 换成不描边、柔和阴影、淡入的字幕；`EXTRA_CSS` 改图解底色、字重和贴纸质感。实例：苹果风（`AI 剪辑/试跑_v7_苹果风`）= 纯黑底去网格、#f5f5f7 / #86868b / #2997ff、字重 700、玻璃质感横条和贴纸、expo 缓出和文字交叉溶解、不砸字、音效压低一档、黑底一拍一句复盘 + 蓝色结尾卡。

**查重**：`variety.py` 读 build.py 写的实际版式序列（自己包的函数也算得到）；和不在同一文件夹的上一条比，用 `--with <那条工程>`。

**呼吸感**：整屏图解时常驻标题和进度条会自动让位；一屏最多 3 组元素，元素之间至少空 60 像素；图解内容从 y≈560 开始，别贴着大标题。

## 版面（1080×1920）

| 区域 | 位置 |
| --- | --- |
| 平台安全区（文字都在这里面） | y 288–1248，x 120–888（y 840 以下右侧到 780，那里是按钮栏） |
| 常驻标题 / 进度条 | y≈292–360 / y 400 |
| 图解：章节小字 / 大标题 | x 90，y 318 / y 360（常驻标题在图解期间淡出让位） |
| 图解内容 | y 560–1100 |
| 字幕 | y 1130 起（`plan.json` 的 `caption_top`） |
| 人像贴纸 | 自动轮换 4 个位置：左中 (175, 650)、左下 (210, 1000)、顶中 (540, 505)、右上 (765, 505)；近景脸大时在 plan.json 写 `face_box: [x0, y0, x1, y1]`（眼睛到下巴），落在里面的位置不用 |
| 人像 + 横条（band） | 默认 y≈485–665（标题下面）；和左侧贴纸不同时出现 |
| 人脸中心（推近的中心） | (540, 760)，`plan.json` 的 `face_y` |

## 时间

- `W("口播里的字")`：字幕里这几个字开始的时刻；`W("所有的", 2)` 第 2 次出现；`W("对比", off=.3)` 再晚 0.3 秒。**新写的视频优先用它**，改了剪辑自动跟着走。
- 也可以写秒数（成片时间）。秒数是按第一次剪（`work/edl_base.json`）算的，之后改剪辑，`build.py` 会按原片时间自动换算。
- 想从头按新剪辑重写秒数：删掉 `work/edl_base.json`，再跑一次 `cut.py`。

## 函数

| 函数 | 作用 |
| --- | --- |
| `scene(t_in, t_out, 章节, 标题)` … `end_scene()` | 一段整屏图解（盖住人像，口播继续），自带 whoosh 进场 |
| `put(t, html, x, y, kind, sfx, v, z)` | 在 (x, y)（元素中心）放一个元素，t 秒出现；`kind`：up / pop / slam / drop / left；返回 id |
| `hide(t, id)` | t 秒把 put 出来的元素淡出 |
| `sticker(t_in, t_out, html, sfx=, slot=, look=, kind=)` | 人像上的贴纸，到点自己消失。**不写 x、y**：位置自动轮换、不连续两次同一处；外观 `look` 自动轮换 card / tilt / note / outline / bubble；入场动作跟位置走。要固定才写 `slot="右上"` 或 `x=, y=`。至少停 1.2 秒（太短会自动延长并报 ⚠） |
| `band(t_in, t_out, html, y)` | 人像 + 横条：人脸留着，一条宽卡放短的图解（节点、对比、数字），到点消失 |
| `punch(t_in, t_out, 文字, 小字, 颜色)` | 大字砸屏：整屏一个词或数字，字号自动适配一行，配 impact |
| `pill(文字, 底色, 字色, 字号)` | 胶囊标签 |
| `node(内部html, 直径, 底色, 描边)` | 圆形节点 |
| `lab(文字, 颜色, 字号)` | 节点下面的小标签 |
| `ic(图标名, 尺寸, 颜色)` | IconPark 图标（`hf/assets/icons/` 里有 73 个，见文件名） |
| `logo(名字, 尺寸)` | 品牌 logo，白底圆角（文件放 `hf/assets/logos/<名字>.svg|png`） |
| `counter(t, 元素id, 数到几)` | 数字从 0 数上去 |
| `typewrite(t, 元素id, 文字, 时长)` | 打字机（配一段轻键盘声 `S(t, 'typing')`，不要一下一下敲） |
| `settext(t, 元素id, 文字)` | 到点换字（计数器 ×1 → ×4） |
| `A(t, 选择器, 从, 到, 时长, 缓动)` / `T(t, 选择器, 到, 时长, 缓动)` | 直接写 GSAP fromTo / to |
| `S(t, 音效名, 音量倍数)` | 音效：whoosh pop tap ding strike sparkle text_slam riser impact typing |
| `broll(t_in, t_out, 文件名, 素材内起点)` | 空镜：这段时间整屏换成空镜（口播继续），淡入、轻推近、淡出；文件放 `hf/assets/broll/`，用 Mixkit 等可商用竖版素材，垫在升华的句子上 |
| `raw_js(代码)` | 其他 GSAP；代码里的秒数用 `{R(秒数)}` 换算 |
| `EXTRA_CSS.append(css)` | 这条视频自己的样式 |

颜色常量：`INK`（墨黑底）`TILE`（卡片）`LINE`（描边）`WHITE` `GRAY` `NEON`（荧光绿）`RED`。现成的样式类见 `scripts/scenes.css`（`.stk` 贴纸、`.vcard` 对比卡、`.step` 步骤行、`.bub` 对话气泡、`.prob` 问题条、`.dash` 虚线、`.strike` 红线……）。

## 常见图解的写法（例子里都有）

| 口播在讲 | 画法 |
| --- | --- |
| 一个模型 / 框架 | 三个圆节点连箭头，先出字母再换图标；讲到哪一格，那一格放大发光，其他变暗 |
| 两个工具 | 两个 logo 卡 + 中间「+」，下面各挂一个能力标签 |
| A 和 B 的区别 | `.vcard` 左右卡 + VS；同一句输入；各自的结果；结论挂在同一组卡片上（划掉 / 发光），不换页 |
| 以前要几步 | `.step` 逐条出现，右上角「手动 ×1…×4」计数，最后变红 |
| 现在一句话 | 对话气泡打字 → 齿轮转 → 文件掉到「桌面」打勾 → 大字「4 步 → 1 句话」 |
| 两个问题 | 两端节点 + 虚线，中间冒出红色警示图标，下面问题条逐条出现 |
| 闭环 / 配合 | 左右两个节点，上下两条虚线，小文件图标沿线飞过去、飞回来，最后长出关系图谱 |
| 结尾关注 | 三格里已讲的打勾、没讲的挂「下期」；手指点「＋ 关注」变成「✓ 已关注」 |

## 自查（`build.py --snap` 出拼图，逐张看）

- 首帧：有人脸、有标题，不是黑屏。
- 字有没有挡脸、出画、和别的元素叠在一起（对比卡里的标签最容易挤）；顶部是不是只有一层、有没有呼吸感。
- `variety.py` 没有 ⚠。
- 对比页：关掉声音只看画面，能不能看出两边差在哪。
- 图解底部离字幕至少 30 像素。
